### MDX 正文

```mdx
「solo engineer 是 CARTA」和「solo engineer 作为 CARTA」中间差的不是字,是语法。
「是」= 名词 = 身份 = 一次定义就完成。Brewster Kahle 是 CARTA。30 年守护 Internet Archive。这件事说完就完。
「作为」= 副词 = 姿势 = 每天重新做一次。今天 commit log,今天守护。明天没 commit log,明天就不是 CARTA。
solo engineer 永远是「作为 CARTA」,不是「是 CARTA」。
因为 solo engineer 没有公司发工资、没有 CEO title、没有 on-call 排班。
solo engineer 唯一的身份证明 = 每天 commit log + 每天还在写。
git reflog 不是历史。git reflog 是 solo engineer 的脉搏。今天 commit 了 = 今天还在心跳。今天没 commit = 今天还没死透。
Brewster Kahle 是 CARTA (固定身份)。
Shawn 是「作为 CARTA」 (每天重新确认)。
不是 Shawn 不如 Brewster Kahle。是 Shawn 没有 Brewster Kahle 的固定身份。
solo engineer 的全部尊严 = 每天重新做的姿势, 不是 30 年一次的称号。
```
