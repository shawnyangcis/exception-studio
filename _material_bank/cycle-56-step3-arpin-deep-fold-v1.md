### 核心功能
- **35B Qwen 模型在 Raspberry Pi 上运行**（用 UD-Q3_K_S dynamic weights for Qwen3.6-35B-A3B）
- **ODB connector** 读取汽车内部数据（diagnostic codes + monitors）
- **Manufacturer cloud service connector** 控制 AC + 开/锁门
- **完整汽车手册 RAG**（owner manual + service manual）
- **agent family 集成**：当在线时跟其他 agent family 通信
- **离线下答 car questions**（如 "when should I add oil and what kind of oil?"）
- **主动 agent 哲学**：当车坏了不能动时，car agent 自动通知 agent family → agent family 自动找火车票
