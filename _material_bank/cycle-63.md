# 「solo engineer as CARTA」

「solo engineer as CARTA」不是「solo engineer 是 CARTA」。
这两个句子差的不是字，是语法。
「是」= 系动词 = 把主语和名词连起来。Brewster Kahle 是 CARTA。30 年守护 Internet Archive。这件事说完就完。身份是铸造出来的，不用每天重做。
「as」= 副词 = 修饰动词。动词代表行为。行为 = 每天重新做一次。今天 commit log，今天还在做。明天没 commit log，明天就没在做。
solo engineer 永远是「solo engineer as CARTA」，从来不是「solo engineer 是 CARTA」。
因为 solo engineer 没有公司发工资，没有 CEO title，没有 on-call 排班。
solo engineer 唯一的身份证明 = 每天 commit log + 每天还在写。

## 副词

「as」是副词，不是系动词。
副词修饰动词，动词代表行为，行为 = 节奏。
节奏就是 solo engineer 守住自己节奏的具体动作。
「as」不是把身份贴上标签，「as」是把姿势写在动词前面。
散文站 anchor v18 五子轴的根轴 = 副词。
副词不定义，副词描述。
描述一个姿势，不是铸造一个身份。
solo engineer 的全部尊严 = 每天描述自己一次，不是 30 年铸造一次。

## 摩擦

solo engineer as friction keeper = 守住摩擦的人。
LLM 时代最大的诱惑 = 把所有摩擦都外包给模型。
让模型写散文、让模型写 commit log、让模型配图、让模型发邮件。
但 solo engineer 的全部尊严 = 守住那些不外包的摩擦。
commit log 是摩擦。frontmatter excerpt 是摩擦。MDX 改一次又一次是摩擦。
散文 #95 重写一次又一次，不是退步，是摩擦。
摩擦不是阻力，摩擦是 solo engineer 守住自己姿势的物理量。
larsfaye 写了 4 篇散文论述 AI 时代不能取消摩擦；Uncle Bob 三年原则守住代码不被一次性外包；coolwulf 13 年浏览器路线不外包给 Chromium。
solo engineer as friction keeper = 不让「review 流水线」卷进来的人。

## 营销

solo engineer as personal brand = 营销是 commit log。
不是「你是谁」，是「你今天 commit 了什么」。
不是 30 年一次的称号，是每天 commit log 的连续姿势。
散文站不审任何人，不接受任何 verified。
散文站的 marketing = 每一篇散文都署 solus opus，每一篇散文都留 commit log。
Freeego marketbar.app 的 marketing = 每一条价格曲线都对应一个人的工作时间。
solo engineer 的 marketing = 不用名字，用 commit。
commit log 是 solo engineer 的名片。
commit log 是 solo engineer 的简历。
commit log 是 solo engineer 的 portfolio。
不是自我描述，是自我记录。
散文站 anchor v18 五子轴的第三轴 = 营销 = commit log = 个人品牌 = 不需要名字的 marketing。

## 节奏

solo engineer as cold water = 不沸腾的人。
数据清洁 > 数据规模。simedw RollTab 5x data 反而更差。
hotorcold.com cold water cold coffee cold code.
coolwulf 13 年浏览器路线不加速。
simedw「算了，挺快乐」。
solo engineer 的节奏 = 不沸腾的节奏 = cold water 节奏。
不追求规模感，不追求融资速度，追求的是每个 commit 的质量。
散文站 anchor v18 五子轴的第四轴 = 节奏 = cold water = 不沸腾 = 数据清洁 > 数据规模。
simedw RollTab 训练数据清洁 5 次，模型反而比清洁 1 次时更差。清洁不是越多越好，清洁是精确删掉不该留的。
solo engineer 的节奏 = 精确删掉不该留的 commit = 精确删掉不该留的散文 = 精确删掉不该留的 paragraph。

## 资本

solo engineer as against capital = 反资本叙事。
散文站不审任何人，不接受任何 verified。
sentinelK V2EX「资本叙事 + AI 时代」五论：顶端挑战 / 程序员组织收缩 / AI 工具中医 / TDD 重制 / 语言省 token。
solo engineer 的反面 = 资本叙事的主语。
solo engineer 永远是宾语，资本永远是主语。
散文站把 solo engineer 写成宾语，不写成主语。
因为 solo engineer 是动作，不是主语；solo engineer 是姿势，不是主体。
资本叙事把 solo engineer 包装成「独立创始人」「一人公司」「超级个体」，那是把 solo engineer 拉成主语。拉到主语 = 拉到资本叙事的语法里 = 拉到需要融资、需要 growth、需要 exit 的赛道里。
solo engineer as against capital = 拒绝被拉到主语 = 拒绝被融资叙事吸收 = 坚持做宾语 = 坚持做动词前的副词。
散文站 anchor v18 五子轴的第五轴 = 资本 = against capital = 拒绝被融资叙事吸收 = 坚持做宾语。

## 收尾

solo engineer as 散文站 = 散文站 = 散文站。
「as」副词性的总和 = 散文站 anchor v18 五子轴（副词 / 摩擦 / 营销 / 节奏 / 资本）。
solo engineer 永远是「as 什么」，从来不是「是 什么」。
因为「as」是姿势，「是」是身份。
solo engineer 没有身份，solo engineer 只有姿势。
今天 commit 了 = 今天还在做 CARTA。
今天没 commit = 今天没在做 CARTA。
solo engineer 的全部尊严 = 每天重新做，不是 30 年一次铸造。
