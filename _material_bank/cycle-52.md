## 散文 #98 — solo-engineer-as-personal-brand (草稿骨架)

### 标题

solo engineer 作为个人品牌 / solus opus personal brand manifesto

### Slug

solo-engineer-as-personal-brand

### Anchor

- Freeego marketbar.app 8/27 ProductHunt + V2EX + HN show 热门 = 一个人做股票市场面板 = solo engineer 的「一个人搞定所有事」可被验证的具体例证
- 「一个人搞定所有事」hero 8/27 已上线 = 散文站主轴
- 「commit log 是 marketing」= 散文站 marketing 哲学 = 散文站 = 「作品即站点, 站点即作品」具体例证 (跟 AcceptMarkdown Andy Kawasaki 同源)

### 起

一人工程的最后一块不是代码,是品牌。

代码可以一行一行写出来,品牌却需要「让别人认得出」。Freeego (一人做 stock marketbar.app) 8/27 在 ProductHunt 和 V2EX 同时热门,展示的不是股票面板,展示的是「一个人搞定所有事」可被外部验证。

「solo engineer as personal brand」= 「solo engineer 作为个人品牌」= 「自己就是品牌」。

### 承

散文站 anchor v8 早已点题：「一人工程 = 一个人 + 一台 PC + 一个 commit log + 一份散文集」。这四块每一块都是个人品牌的载体：

- **commit log** = 时间线 = 散文站 GitHub 仓库 `shawnyangcis/exception-studio` 的全部 commit = 「你认得出我」
- **散文集** = 立场 = 散文站 Vercel 部署 + content/works/index.json 的全部散文 = 「我认得出我在写什么」
- **站点** = 门面 = 散文站首页 hero + 散文列表 + notes + about = 「我认得出我的形状」
- **HN show / ProductHunt / V2EX** = 出口 = solo engineer 跟外部世界打招呼的具体场所 = 「你认得出我从哪里来」

个人品牌 = 「你认得出我」的具体物质载体集合,不是 follower count。

### 转

「solo engineer as personal brand」的「as」不是「是」,是「作为」。「是 personal brand」= 状态论 = 「我有品牌」。「作为 personal brand」= 姿势论 = 「我正在做 brand」= 「我的 commit log 正在是 brand」= 「我的散文集正在是 brand」= 「我的 Vercel 站点正在是 brand」。

Freeego marketbar.app 上 ProductHunt = 「他正在做 brand,不是他有名」。zedeus Nitter 7+ 年 = 「他正在做 brand,即使 X Corp C&D 拔掉了他,GitHub 上的 commits 还在」。andros Fenollosa 6 个自托管域名 = 「他正在做 brand,即使没人看见,域名还在」。

「as」的副词性 = 行为性 = 正在做 = 散文站个人品牌的具体形态。

### 合

散文站 marketing 哲学 = 「commit log 是 marketing」= 「散文集是 marketing」= 「Vercel 站点是 marketing」= 「solo engineer as personal brand = 我在写散文这件事本身就是 brand」。

散文站 hero 早已说：「今天 我一个人搞定所有事」(commit bfa58d68 / vol.5 三篇 + vol.6 三篇)。散文 #98 是这一行的散文版 = 「我一个人搞定所有事,而且我自己说出来了 = 个人品牌」。

散文 #98 不是 marketing 教程,是「solo engineer 作为个人品牌」的存在性陈述 = 散文站 anchor v18 第二个副词性子轴 (营销)。
