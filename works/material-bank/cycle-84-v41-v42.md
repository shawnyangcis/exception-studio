- **fuzzer 地址**：https://github.com/daedalus/fuzzer/
- **Bug 严重度**：Medium (reliable DoS, not immediate code-execution primitive)

### Bug 详情
- **位置**：`libavformat/vpk.c:89` (Sony PS2 VPK demuxer)
- **类型**：Integer Divide-by-Zero (SIGFPE)
- **触发链**：
  1. `vpk_probe` 匹配 VPK magic 分配 demuxer
  2. `vpk_read_header` 解析 24-byte header (nb_channels = 0 at 0x0e–0x11)
  3. `vpk_read_packet` 最终-block 分支除零
- **Crash 输入**：21 bytes crafted (`20 4b 50 56 56 50 00 f8 04 00 3b 03 61 39 56 32 36 36 30 38 50`)
- **Fuzzer 数据**：495,211 execs to find / 13,188 entries corpus / 10h 43m elapsed
- **修复**：在 `vpk_read_packet` 顶部加 `if (par->ch_layout.nb_channels == 0) return AVERROR_INVALIDDATA;`

### 关键信号
- **「vibecoded fuzzer」= AI 协助 solo engineer 找 infra bug**
- **Darío Clavijo 是 solo dev**：个人 @daedalus fuzzer repo, 个人 GH issue, FFmpeg member Jun Zhao 引用其 PR 修复 (#24297)
- **FFmpeg 是 critical infra**：every Linux / Android / browser / video tool 用 FFmpeg
- **Sony PS2 VPK demuxer** = 极度边缘 legacy container format = solo engineer 关注「无人在意」的角落
- **21-byte SIGFPE** = 极小 input trigger 极广 reach = vibecoding ROI
