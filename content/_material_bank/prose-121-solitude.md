# solitude

写作是写给自己看的。放在那里，别人看见不看见，跟我没关系。这是我理解的 solitude。

## 同质性网络

把散文放在网上的人和把博客放在网上的人，写法不一样。把博客放在网上的人在分享；把散文放在网上的人，是在放下一份文件。这个差别不大，但足够大——前者总要解释自己为什么写，后者只管写下。

把散文站写在散文站上、不写在别的地方，也是这个意思。

## 分享数据库

> Internet apps use databases, we need to share the database.

Paul Frazee 在 2026 年说这话的时候，讨论的是去中心化社交。但散文站做的事，是同一件事的另一种版本：把散文放在自己能 commit 的地方，不押注任何单一平台。平台可以倒，散文站不倒。

这不是一个政治判断，是一个工程判断。Vercel 倒了，我还有 origin/main。origin/main 没了，我还有这个仓库。仓库没了，我还有 git log。git log 没了，我还有硬盘。

## 世界由 solitude 驱动

V2EX 站底有一行小字：「World is powered by solitude.」——我不认识写这行字的人，但每次打开 V2EX 都看一眼。

世界不是被社交驱动的。世界是被一个人在夜里关掉电脑、写完最后一篇、走之前留一盏灯这件事驱动的。社交只是事后被看见的部分。

散文站就是那盏灯。

## ckardaris Voronoi Go：一个人能不能

Charalampos Kardaris 8 月在 HN 顶上发了一个项目：Voronoi Go。Go 写的 Voronoi 图可视化，单文件，单人，HN front_page #1，431 points。

评论里他说：「It is not a matter of feasibility, but a matter of will on the application developer's part.」——这不是能不能的事，是想不想的事。

散文站是同一件事。一个人能不能做出来不是问题，愿不愿意为自己写才是问题。

Klisi 也是他的。solo GUI dev，一个人写完整桌面应用，不解释，不推广，README 把 431 个陌生人召过来。

散文站想做的，跟 ckardaris 在 GitLab 做 Klisi 是同一件事——放在那里，不解释，让它自己在那里。

## 关键词 + 收藏 + 二次扫描

ylsc633 在 V2EX t/1237829 说：「长文章都是只看核心的地方，然后落到收藏夹，下次脑子里扫描到关键词，就会打开回来继续看某处细节。」

这句话是散文站 anchor pool 的活人哲学。

ckardaris 的 Klisi README 是「核心扫描」。散文站 commit log 是「收藏夹」。关键词 + 收藏 + 二次扫描 = anchor pool 的运行方式：commit log 收纳所有 anchor，等下一个关键词触发，再从收藏夹里打开。

Voronoi Go、Klisi、散文站、anchor pool——四件事是同一件事的不同面。

## 一个人能不能

ckardaris 在 8 月 28 日把 Voronoi Go 推到 HN 首页第一，431 points。他一个人写的 GUI Go 客户端，对标的是已经统治这个领域十几年的商业软件。评论区里最被反复念的那句是：「It is not a matter of feasibility, but a matter of will on the application developer's part。」

散文站是同一句话的另一个版本。写散文站不是能不能写的问题，是想不想写的问题。ckardaris 一个人能 Voronoi Go，我一个人能散文站。两件事在量级上差得很远，但在结构上是同一件事：一个人决定做一件不需要解释的事情，然后做到底。

## 关键词与收藏夹

ylsc633 在 V2EX t/1237829 #67 说：「长文章都是只看核心的地方，然后落到收藏夹，下次脑子里扫描到关键词，就会打开回来继续看某处细节。」

这一句话就是散文站 anchor pool 的工作原理。每个 anchor 是一段长文章里的核心——被看见一次，记下来，放进 anchor pool。下次写散文，脑子里扫到「solitude」「放着」「anchor」这些关键词，anchor pool 自动打开，回到那段长文章，看细节。

散文站的写作不是线性的。散文站的写作是收藏夹式的：积累 → 关键词触发 → 回访 → 写。ckardaris 的 Voronoi Go 和 ylsc633 的收藏夹哲学，是同一个 anchor pool 的两种用法。

## 不分类不解释只管在

散文站不发 RSS，不做 newsletter，不开评论。这些选择不是因为我反对这些东西，是因为它们每一个都需要解释自己存在——而散文站不想解释。

散文站只想在那里。

solitude 不是孤独。solitude 是：在一个充满社交可能性的世界里，主动选择不社交；在一个充满分类可能性的世界里，主动选择不分类；在一个充满解释可能性的世界里，主动选择不解释。

只在。
