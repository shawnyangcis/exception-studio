## 散文主题

散文站为什么是这个 shape：单文件 = 一个文件就能跑。

散文 #119 是散文站对「单文件程序」哲学的散文化。solo engineer 写软件、写散文、写工具、写游戏，都倾向于单文件——因为单文件意味着：能 commit、能 fork、能保留、能理解。

## anchor pool（五 anchor）

### v51 Bento

Bento 是一个把 HTML + CSS + JS 全部塞进单个 .html 文件的项目，哲学是「distribution as a single file」。一个文件 = 一切。散文站追这个哲学。

### v52 Colibrì

Colibrì 是 HN show 上的单文件浏览器项目，作者说「I want my browser to be one file I can open in 20 years」。散文站追这个哲学：散文站是我 20 年后还能打开的东西。

### v55 LatticeDB

LatticeDB 是 solo engineer 写的单文件图数据库（Zig 实现），HN show 拿过 HN 首页。一个 .zig 文件实现一个 graph DB。散文站追这个哲学：散文站 commit log 是单文件哲学的具体应用。

### v60 Voronoi Go

Voronoi Go 是 solo engineer igpay 写的全栈 indie game + community bot + 异步对弈，单一可执行文件 = 一切。游戏本体、服务器、客户端、bot 全在一个文件里。散文站追这个哲学。

### v103 Luanti 单文件游戏引擎

Luanti（Minetest 后继）支持「单文件游戏引擎」打包：一个 .lua 文件 = 一个完整的游戏。这是 solo engineer indie game developer 的具体形态。散文站追这个哲学。

## 散文站哲学主轴

单文件 = 不需要框架、不需要平台、不需要安装。commit 即发布，git log 即历史，repository 即 backup。20 年后还能打开。
