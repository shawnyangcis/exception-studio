## 核心论点
1. **「keyboard-driven ≠ terminal-only」**: TUIs 被 preferred 不应该是因为 keyboard-driven, GUIs 也可以 keyboard-driven
2. **「It is not a matter of feasibility, but a matter of will on the application developer's part」** ← anchor
3. **GNOME HIG reference**: 引用 GNOME Human Interface Guidelines ——「Just as it should be possible to perform every action with a pointing device, every action should also be possible with the keyboard」+ 「it should be possible to move around and interact with every part of your user interface using the keyboard」
4. **Solo dev application**: Klisi (https://gitlab.com/ckardaris/klisi) — 自己写的 GUI 应用键盘快捷键全覆盖,作为「matter of will」的具体例证
