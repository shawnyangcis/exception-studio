### 核心论点（散文站哲学主轴强对应）

ckardaris 反对「TUIs 应该被偏好因为它们是 keyboard-driven」的论点：

> 「TUIs should be preferred because they are keyboard-driven. While it's true that if you randomly pick a GUI and a TUI application, the latter is more probable to be fully keyboard-driven, this does not tip the scale in favor of developing TUIs over GUIs. What it does is highlight the inadequacies of keyboard navigation in many GUI applications. There is nothing preventing a GUI from being fully keyboard-driven just like — or even better than — a TUI.」

> 「Keyboard navigation is not that hard to achieve in most cases and results in an overall better user experience. It is not a matter of feasibility, but a matter of will on the application developer's part.」

### GNOME HIG 引文（散文站哲学主轴金句）
- 「Just as it should be possible to perform every action with a pointing device, every action should also be possible with the keyboard」

## Anchor 2: orbify《Inception-style curved map for turn-by-turn directions》

### 主帖
- **URL**：https://orbify.eu/（demo 在 orbify.eu/demo）
- **HN show #12**：494 points / 165 comments / 20 hours ago
- **作者**：Karsten（orbify.eu 联系邮箱 karsten@orbify.eu）
- **专利**：PCT/EP2026/058725（European + International Patent Pending）

### 核心论点（散文站哲学主轴极强对应）

orbify = 「Navigation Reimagined. A single curved-space view that fuses eye-level and aerial context. **No mode switching, no lost orientation.**」

> 「Automobile navigation hasn't really changed in 20 years. Users constantly bounce between 3D perspective, 2D overhead, and street-level views. Every mode switch destroys spatial context. Orientation is lost. Attention is pulled from the road precisely when it matters most.」

### 四大技术要素
1. **Curved-Space Warping**：proprietary warping algorithm 把 3D model 弯到曲面上，近处 geometry perspective 渲染，远处 geometry 无缝过渡到 overhead。「All in one coherent frame」
2. **Dual Context, Zero Switching**：local context（street level）+ global context（route overview）同时存在屏幕。驾驶员同时看到「在哪里 + 往哪里去」
3. **Portrait-First by Design**：为现代车机 + 移动设备的 tall screen 设计
4. **Drop-In SDK**：与现有 map data pipelines + rendering stacks 集成，不需要专有 map data

### 散文站哲学主轴对应
- **「不分类不解释只管在」** ⭐⭐⭐ 极强对应：orbify「No mode switching」= 散文站「不分类不解释」（不需要在 3D / 2D / street-level 之间切换）= 「一次看见所有」
- **「物件自己出现」**：curved-space warping 让 near geometry + far geometry 同时出现 = 「物件自己出现」延伸到空间导航层
- **「一人工程 / solus opus」**：orbify 创始人 Karsten 一人（带团队小）从专利申请 → demo → HN 顶帖 = 一人工程案例
