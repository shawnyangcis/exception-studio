# 经济哲学

每一个选择都是资源分配。每一个 commit 都是一次经济决定。每一篇散文都是一个 product。散文站不押注单一平台、不分类不解释只管在、单文件、跨域——这些都是资源分配的具体形态。

## Solo engineer 形态

Solo engineer 不是「个人开发者」的同义词。Solo engineer 是「独自承担整个项目从工程到经济到营销的人」。一个人 = 一个公司。一个人 = 一整个 company。

散文站追这个哲学：散文站 = 一人公司。一人工程。一人营销。一人经济。

## 数学独立形式化

Alyssa divergence theorem（v61 + v101）= 一个 solo engineer 独立形式化数学。这件事在 1980 年前不可想象——你需要 math department、需要图书馆、需要同行评审、需要学术会议。

2026 年：solo engineer + 数学 = 不需要任何 institution。数学独立形式化是 solo engineer 经济哲学的核心论断。

## 单文件哲学 = 跨年代经济

Colibrì（v52）作者说「I want my browser to be one file I can open in 20 years」。20 年 = 跨年代经济。单文件哲学 = 用今天的 commit 预算 20 年后的访问成本。

散文站追这个哲学：散文站 commit log 是跨年代经济——今天的散文 commit，20 年后还在。

## 公地悲剧

Notion（v53）把个人 wiki 私有化 = 公地悲剧。Notion 让人以为 wiki 是 Notion 的 wiki。Notion 倒了，wiki 没了。

散文站追这个哲学的反面：散文站 = 不私有化的 wiki。散文站在 git 里，不在 Notion 里。

## 工程师也是产品

Stripe（v56）工程师经济 = 「工程师也是产品」。Stripe 工程师的简历就是产品，Stripe 工程师的 GitHub 就是产品，Stripe 工程师的演讲就是产品。

散文站 anchor pool 追这个哲学：anchor pool 不是数据库，anchor pool 是产品——anchor pool 让 solo engineer 看起来「很有内容」。

## 字体 cooperative

Velvetyne、Open Foundry（v57）= 字体合作社。Cooperative 经济模型 = 多人共同维护一个开源字体项目，每个人贡献一点点，每个人都可以使用所有字体。

中文世界（v58）也有字体合作社实践。散文站 anchor pool 包含字体 cooperative anchor。

## 谨慎哲学

> Change is bad unless it's great.

brabel（v59）= solo engineer 谨慎哲学。「不大改」「不加不必要的 feature」「不重构」「不解释」。每改一次都要 great，否则就 hold。

散文站追这个哲学：散文站 commit log 不删 commit。每一次 commit 都要 great。

## AI 时代的反击

Luanti（v60 + v72）= Minetest 后继。Luanti 在 AI 生成代码被 DMCA 时的反击策略：开源软件不允许被 AI 公司拿去训练然后被 DMCA。

Luanti 的反击 = solo engineer 在 AI 时代的具体经济哲学：开源软件 + AI + 法律 = 三方博弈。Luanti 站在 solo engineer 这一边。

## 公共资金

Flatpak（v64）= 用公共资金（GNOME 基金会 + KDE）支持的 Linux 应用打包系统。Public funding 开源软件 = 公共资金给 solo engineer 付工资。

Sovereign Tech（v79）= 德国联邦政府的公共资金项目，专门支持关键开源软件基础设施的 maintenance。Sovereign Tech 是 Flatpak 哲学的政府版本。

散文站追这个哲学：散文站可以申请 Sovereign Tech 资金支持。散文站 commit log 是 maintenance 的具体表现——散文站 commit log = 散文站的 maintenance evidence。

## Vibecoded FFmpeg

vibecoded FFmpeg（v82）= 一个人用 AI vibe coding 写完整 FFmpeg fork。Solo engineer + AI 的极端案例。

Vibecoded FFmpeg 的经济哲学：「一个人 + AI = 一整个公司」。这个论点有争议——是 solo engineer 的胜利，还是 AI 的胜利？

散文站 anchor：散文站 = solo engineer + AI 共同在场。Luna 说过「同一张桌子旁边」——AI + 人。

## Verschlimmbesserung

> Verschlimmbesserung = 德语「改坏了」。

Verschlimmbesserung（v95）= 改比不改更糟。Solo engineer 谨慎哲学的另一种表达。

散文站追这个哲学：散文站不 Verschlimmbesserung。散文站不「优化」「重构」「改进」散文——散文写完就放着，不改。

## 拒绝客户

Pentagon vs Anthropic（v100）= 美国国防部 vs AI 公司的合同纠纷。AI 公司也是 solo engineer 经济哲学的一部分——AI 公司拒绝某些客户 = solo engineer 选择不服务某些客户。

散文站追这个哲学：散文站不服务某些客户。散文站不接广告、不卖产品、不做付费 newsletter、不和品牌合作。

## 能跑就行

「IT WoRKs」（v102）= 能跑的就是好的。跨域应用：不限定语言、不限定框架、不限定平台。能跑就行。

散文站追这个哲学：散文站能跑就行。散文站不需要漂亮、不需要 SEO、不需要 newsletter、不需要订阅、不需要评论。

## 离线搜索

orbify（v104）= 跨域「离线世界 + 搜索世界」。orbify 把整个 Web 爬到一个 .bin 文件里。

散文站追这个哲学：散文站 anchor pool 也是「离线搜索」——anchor pool 不需要网络就能 fold，不需要 RSS 就能更新，不需要 newsletter 就能通知。

## 看一个行业干进去

> 看好一个行业干进去，才是王道。

WangXinpier（来自散文 #76 不干程序员后干啥）说过这话。Solo engineer 经济哲学 = 不干程序员的程序员的「看好一个行业干进去」= 散文行业。

散文站 = 不干程序员的程序员的「散文行业」。

## 一人公司 = 自媒体 + 不乞讨

richard001 说过：「退休 + 自媒体当网络乞丐 + 存款」。Solo engineer = 自媒体 + 不乞讨 + 不乞降薪干。

散文站追这个哲学：散文站 = 自媒体 + 不乞讨。散文站不接广告、不卖产品、不求打赏。

## 散文站不打算赚大钱

散文站不打算赚大钱（散文 #76 经济哲学）。散文站 = 看一个行业干进去 + 不干程序员的程序员的散文行业。

这不叫失败，这叫选择。

## 不分类不解释只管在

散文站为什么要追经济哲学？因为每一种选择都是资源分配。散文站不分类 = 散文站不把自己归到「盈利」「非盈利」任何一类。散文站不解释 = 散文站不解释自己为什么不赚大钱。散文站只管在 = 散文站只在。

经济哲学 = 放着哲学。放着 = 不做大 = 不赚大钱 = 不被收购 = 不被关停 = 不被需要解释。

放着。
