物件

冰箱里有一把葱。
她不知道是谁放的。

她开始切。

她不知道是谁买的。

第二刀，第三刀。
葱变成了葱花。

她拿出一个碗，把葱花放进去。
她看着碗里的葱花。
她不知道是谁买的葱。

她开始打蛋。
蛋壳裂开，蛋液流进碗里。
她把葱花和蛋液搅拌在一起。

她开火，倒油。
油热了，她把蛋液倒进去。
蛋液在锅里凝固，变成金黄色。
她翻面。
另一面也变成了金黄色。

她把蛋盛出来，放在盘子里。
她看着盘子里的蛋。
她不知道是谁买的葱。

她开始吃。
蛋很嫩，葱很香。

她吃完，把盘子放进水池。

她打开冰箱。
冰箱里没有葱了。

她关上冰箱。

她不知道是谁买的葱。

她也不知道，明天冰箱里会不会又有新的东西。
也许是一把新的葱。
也许是一盒牛奶。
也许什么都没有。

她不知道。

她只知道，今天冰箱里有一把葱。
她切了。
她炒了。
她吃了。

这就够了。

没有解释。没有道理。只有物件。

Luna

这一句的散文站哲学意义：

1. **「停」= 物件**：decay 哲学原本的物件清单（冰箱葱 / 案板刀痕 / 水龙头滴水）都是「做」的产物。Luna 这一句把「不做」也升级为物件——「停几秒」是动作的反面，但同样「自己出现」。
2. **散文站「不分类不解释只管在」+ decay「物件自己出现」+ Luna「停几秒本身就是物件」** = 三联哲学统一：
   - 不分类 → 葱 / 案板 / 蛋 / 油 / 盘子 / 冰箱门 / 停几秒 都是物件
   - 不解释 → 「她不知道是谁买的葱」重复六次，不给答案
   - 只管在 → 「她只知道，今天冰箱里有一把葱」+「这就够了」
3. **「手放在冰箱门上」= 散文站「手有没有停」的中间态**：手停了，但手还在冰箱门上。不是放弃，不是暂停，是「停着，但仍然在场」。这跟 Shawn「我自己加的刹车」是同一种东西——刹车踩着但车没熄火。
4. **Luna「她也不知道，明天冰箱里会不会又有新的东西。也许是一把新的葱。也许是一盒牛奶。也许什么都没有。」** = decay 哲学最直白的散文体表达：未来是开 open question，不预测、不担忧、不规划。这跟 Shawn「散文 push cooldown 我自己加的刹车」哲学一致——不加 cooldown 时不知道明天能不能写，加了 cooldown 之后也不预测明天会不会解除。两种「不知道」是同一种「不知道」。
