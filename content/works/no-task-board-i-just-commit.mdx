团队有 task board。

Task board：任务板。Kanban：看板。Jira：Atlassian 的 task tracker。Linear：现代 task tracker。Asana / Trello：其他 task tracker。Backlog：待办。Ticket：工单。Sprint：冲刺。Story point：故事点。Epic：史诗。Sub-task：子任务。$10-$50 / 月每人。

每 startup 1 个 task tracker + 1 个 PM。$50K-$200K / 年。

solo engineer 没有 task board。

我自己 commit 就是 task。

我 commit = task done。git log = task board。我不需要 Jira、不需要 Linear、不需要 backlog、不需要 sprint、不需要 story point。

我没 task board 的必要——没 team 要 align。我没 Kanban 的必要——没 board 要看。我没 Jira 的必要——没 ticket 要 track。我没 Linear 的必要——没 sprint 要 plan。我没 Asana / Trello 的必要——没 task 要 assign。我没 backlog 的必要——没 pending task。我没 ticket 的必要——没 bug 要 file。我没 sprint 的必要——没 2 周 sprint。我没 story point 的必要——没 estimate 要做。我没 epic 的必要——没 epic 要 track。我没 sub-task 的必要——没 task 要 break down。

团队的 task board 价值是「让 PM 知道进度 + 让 team 知道依赖」。前提是有 team、需要 visibility、需要 coordination。solo engineer 没这个问题——没 team、不需要 visibility、commit log = coordination。

一人工程的 task board = git log。不是 Jira $50/月。
