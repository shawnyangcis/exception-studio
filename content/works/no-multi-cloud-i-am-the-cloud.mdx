团队有 multi-cloud。

Multi-cloud：多云。Cloud portability：云可移植性。Cloud agnostic：云无关。Vendor lock-in：供应商锁定。Cross-cloud：跨云。AWS：Amazon Web Services。GCP：Google Cloud Platform。Azure：Microsoft Azure。$100-$10000 / 月 in multi-cloud infrastructure.

每 startup 1 个 AWS + 1 个 GCP + 1 个 Azure + 1 个 cloud architect。$300K-$700K / 年.

solo engineer 没有 multi-cloud。

我自己就是 multi-cloud。

我想 migrate 就 migrate、想 port 就 port、想 switch 就 switch、想 abstract 就 abstract。我不需要 multi-cloud、不需要 cloud portability、不需要 cloud agnostic、不需要 vendor lock-in、不需要 cross-cloud、不需要 AWS、不需要 GCP、不需要 Azure.

我没 multi-cloud 的必要——Vercel + commit log 是 multi-cloud。我没 cloud portability 的必要——没 portability。我没 cloud agnostic 的必要——没 agnostic。我没 vendor lock-in 的必要——commit log 是 vendor agnostic。我没 cross-cloud 的必要——没 cross-cloud。我没 AWS 的必要——Vercel > AWS。我没 GCP 的必要——Vercel > GCP。我没 Azure 的必要——Vercel > Azure。我没 $100-$10000 / 月 的必要——Vercel free。我没 cloud architect 的必要——没 architect。我没 $300K-$700K / 年 的必要——没 multi-cloud strategy.

团队的 multi-cloud 价值是「让 workload 跨云部署 + 减少 vendor lock-in + 提高可用性」。前提是有 enterprise workload、需要 vendor avoidance、需要高可用。solo engineer 没这个问题——访问量 1000、Vercel single-cloud 够用、commit log = vendor agnostic.

一人工程的 multi-cloud = Vercel + git commit。不是 AWS + GCP + Azure $10000/月 + cloud architect.
