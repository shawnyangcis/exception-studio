团队有 culture。

Culture：公司文化。Shared values：共享价值观。Company culture：5-10 个 value。Cultural fit：hire 的时候看 culture。Employee handbook：100 页 handbook。Values deck：5 张 slide。Culture deck：Netflix / Stripe / Gitlab culture deck。

每 startup 1-2 个 culture officer + 1-2 个 people ops。$300K-$1M / 年。

solo engineer 没有 culture。

我自己就是 culture。

我写散文 = culture。我 commit = values。我不需要 culture officer、不需要 people ops、不需要 culture deck、不需要 values deck、不需要 employee handbook、不需要 cultural fit。

我没 culture 的必要——没人要 fit。我没 shared values 的必要——我没 value 共享。我没 company culture 的必要——没 company。我没 cultural fit 的必要——我没 hire。我没 employee handbook 的必要——没 employee。我没 values deck 的必要——散文 = values deck。我没 culture deck 的必要——commit log 是 culture deck。

团队的 culture 价值是「让员工知道 expected behavior + alignment」。前提是有员工、需要 alignment、需要 retention。solo engineer 没这个问题——没员工、不需要 alignment、commit log 是 retention。

一人工程的 culture = commit log + 散文。不是 $1M culture officer。
