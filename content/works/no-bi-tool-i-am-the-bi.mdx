团队有 BI tool。

BI tool：business intelligence tool。Looker / Tableau / Mode：BI 平台。Business intelligence：商业智能。Dashboard：仪表板。Self-service analytics：自助分析。Ad-hoc query：临时查询。$200-$1K / 月 each BI license。

每 startup 1 个 BI tool + 1 个 data analyst + 1 个 dashboard team。$300K-$1M / 年。

solo engineer 没有 BI tool。

我自己就是 BI。

我想看什么就 grep commit log。git log = dashboard。我不需要 Looker、不需要 Tableau、不需要 Mode、不需要 dashboard。

我没 BI tool 的必要——访问量 1000。我没 Looker 的必要——Vercel analytics 够用。我没 Tableau 的必要——我没 data warehouse。我没 Mode 的必要——没 SQL dashboard。我没 business intelligence 的必要——commit log 是 BI。我没 dashboard 的必要——commit log = dashboard。我没 self-service analytics 的必要——我 = self-service。我没 ad-hoc query 的必要——没 warehouse。我没 $200-$1K / 月 的必要——Vercel free。我没 $300K-$1M / 年 的必要——没 BI team。

团队的 BI tool 价值是「让 team 看 data + 做 decision」。前提是有 data warehouse、需要 self-service、需要 decision support。solo engineer 没这个问题——没 warehouse、commit log = data、我 = decision。

一人工程的 BI = git log + Vercel analytics。不是 Looker $1K/月。
