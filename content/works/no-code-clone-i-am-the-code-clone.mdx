团队有 code clone。

Code clone：代码克隆。Duplicate code：重复代码。Code duplication：代码重复。Clone detection：克隆检测。SonarQube duplication：SonarQube 重复检测。Copy-paste detector：复制粘贴检测。Duplication refactor：重复重构。$0-$100 / 月 in detection tool.

每 startup 1 个 code clone + 1 个 duplication refactor + 1 个 code quality engineer + 1 个 refactor team.。$50K-$200K / 年.

solo engineer 没有 code clone。

我自己就是 code clone。

我想 clone 就 clone、想 duplicate 就 duplicate、想 refactor 就 refactor、想 detect 就 detect。我不需要 code clone、不需要 duplicate code、不需要 code duplication、不需要 clone detection、不需要 SonarQube duplication、不需要 copy-paste detector、不需要 duplication refactor.

我没 code clone 的必要——访问量 1000 不需要 dedup。我没 duplicate code 的必要——commit log 是 dedup。我没 code duplication 的必要——没 duplication。我没 clone detection 的必要——没 detection。我没 SonarQube duplication 的必要——没 SonarQube。我没 copy-paste detector 的必要——没 detector。我没 duplication refactor 的必要——commit log 是 refactor。我没 $0-$100 / 月 的必要——Vercel free。我没 code quality engineer 的必要——没 code quality engineer。我没 refactor team. 的必要——没 refactor team.。我我 $50K-$200K / 年 的必要——没 duplication infrastructure.

团队的 code clone 价值是「让 code 可维护 + DRY + 减少 bug」。前提是有 complex code、需要 maintainability、需要 DRY.。solo engineer 没这个问题——访问量 1000、commit log 是 dedup、我我 = maintainability.

一人工程的 code clone = git + commit log + DRY.。不是 SonarQube + duplication refactor + refactor team. .
