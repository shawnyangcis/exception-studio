团队有 JIRA。

JIRA：project management + issue tracking。Linear：modern issue tracking。Asana：team task management。Trello：Kanban board。GitHub Issues：developer issue tracking。Monday.com：team OS。ClickUp：all-in-one。$7.16-$14.32 / user / 月.

每 startup 1 个 JIRA + 1 个 PM + 1 个 sprint planning。$100K-$300K / 年。

solo engineer 没有 JIRA。

我自己就是 JIRA。

我想 track 就 track、想 issue 就 issue、想 sprint 就 sprint、想 backlog 就 backlog。我不需要 JIRA、不需要 Linear、不需要 Asana、不需要 Trello、不需要 GitHub Issues。

我没 JIRA 的必要——访问量 1000 不需要 issue tracking。我没 Linear 的必要——没 Linear。我没 Asana 的必要——没 team task。我没 Trello 的必要——没 Kanban。我没 GitHub Issues 的必要——commit log = issue。我没 Monday.com 的必要——没 Monday。我没 ClickUp 的必要——没 ClickUp。我没 $7.16-$14.32 / user / 月 的必要——Vercel free。我没 PM 的必要——没 PM。我没 sprint planning 的必要——没 sprint。我没 $100K-$300K / 年 的必要——没 PM。

团队的 JIRA 价值是「让 issue tracking + sprint planning + team coordination」。前提是有 team、需要 tracking、需要 coordination。solo engineer 没这个问题——我是 1 个 engineer、不需要 tracking、commit log = coordination。

一人工程的 JIRA = git commit log。不是 JIRA $14.32/user/月。
