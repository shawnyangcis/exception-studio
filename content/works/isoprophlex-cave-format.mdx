# 洞穴人格式：plink 是 plink

> HN simedw 帖子评论 isoprophlex：
> 「man hits thing thing go plink machine hear plink machine make many more plink man happy for plink is fun man not hit machine with club or scream on orange site man leave cave and touch plant」

「man hits thing thing go plink」
「man happy for plink is fun」

HN 经典洞穴人格式。
素朴到不能再素朴。

# 一句洞穴话 = 整个 simedw app

整段洞穴话翻译：

- 男人打东西 → 人弹琴
- 东西发出 plink → 琴响
- 机器听到 plink → iPhone 麦克风
- 机器做出更多 plink → 模型续写
- 男人开心了 → 用户笑了
- 男人不打机器也不在橙色网站上骂人 → 用户不打 iPhone
- 男人离开洞穴去摸植物 → 用户关 app 去浇花

整段话 = simedw 半年做的事 + 整个 iPhone app + 整个 125M 模型 + 整个 iOS 部署。

洞穴话 50 字。
项目实际代码 + 模型 + app + 文档 + HN 帖子 + 审核 = 几十 MB。

50 字 > 几十 MB。

# 洞穴人格式是什么

洞穴人格式（caveman speak）：

- man + verb + thing
- 不加冠词
- 不分时态
- 不分单复数
- 不抽象

例子：

- man hits thing thing go plink
- woman see man man smile
- machine make noise noise big

表达任何事用最简单的字。

# 为什么 HN 用洞穴人格式

HN 用洞穴人格式的原因：

- 嘲讽「过度解释」
- 反讽「花哨术语」
- 让人秒懂
- 幽默感

isoprophlex 用洞穴人格式描述 simedw app：

- 不是因为原始人
- 是因为 simedw app 真的简单
- 「弹琴 + 听到 + 生成 + 开心」
- 没有复杂概念

复杂概念会破坏洞穴话。
能洞穴话 = 真简单。

# simedw app 真简单

simedw app 的洞穴话版本：

- 弹 8 个音
- 模型生成下一个
- iPhone 发声

三句话 = simedw app。

OpenAI app 的洞穴话版本：

- 男人敲字字给机器
- 机器想很久
- 机器回字

也是三句话。
但「想很久」是黑盒。
「想很久」不是洞穴话能描述的。

simedw app 真简单。
OpenAI app 假装简单。

# 洞穴人格式 vs README

simedw 的 README 是 9 段论文式：

- 训练数据
- 架构
- 实验
- DPO
- 评估
- 模型
- 部署
- 没走通的
- 作者姿态

洞穴话版本：

- man makes thing
- thing make plink
- man happy

README 是论文。
洞穴话是素朴。

两个版本都说同一个产品。
两个版本都是真的。

# 一人工程的素朴哲学

simedw 的产品哲学是：

- 简单 = 好
- 复杂 = 不好
- 「想很久」 ≠ 「好」
- 「plink → plink」= 好

一人工程的素朴版本：

- 一个人 + 一个 idea
- 一个 idea → 一个产品
- 一个产品 → 一个用户
- 一个用户 → 一个人弹 + 机器接

不需要 175B 参数。
不需要 1000 个工程师。
不需要 AGI framing。

# 洞穴人格式 vs AGI framing

OpenAI 的 AGI framing：

- 通用人工智能
- 解决一切问题
- 改变世界
- AGI 前夜

洞穴话版本：

- man make smart thing
- thing help man with thing
- man happy
- man think thing is smart

AGI framing 复杂。
洞穴话简单。

两个 framing 是同一个东西：

- AGI = 智能机器
- 洞穴话 = smart thing

# 一人工程的态度

simedw 的态度：

- 我的 app 是 plink → plink
- 不是 AGI
- 不是智能
- 是「弹琴 → 听到 → 生成 → 开心」

isoprophlex 的洞穴话：

- 用 50 字描述 simedw 半年
- 比 50 MB README 还准
