plink / note / training / ship / realtime / pipeline / readme / evaluation / love / privacy / future 十一层抽象之后，第十二层是 quit。

## quit 是什么

quit = solo engineer 放弃一个项目 = 关闭仓库 + 撤回 App Store + 写一个 README「项目停止维护」。

不是失败，是完成。

大公司项目很少 quit——靠 PR + 维护模式 + community 维持。
一人工程可以 quit——同一个人决定。

## quit 是抽象层第十二层

plink = 抽象层 1（领域）
note = 抽象层 2（表示）
training = 抽象层 3（方法）
ship = 抽象层 4（部署）
realtime = 抽象层 5（运行模式）
pipeline = 抽象层 6（流程）
readme = 抽象层 7（文档）
evaluation = 抽象层 8（评测）
love = 抽象层 9（动机）
privacy = 抽象层 10（隐私）
future = 抽象层 11（未来）
quit = 抽象层 12（退出）

quit 是 12 层的最后一层。

11 层是「怎么造 + 怎么评 + 为什么造 + 下一步做什么」，quit 是「什么时候停」。

## quit 是 solo engineer 的关键决策

simedw 8/8 上传 App Store，8/19 上线。到现在 11 天。没有 quit 计划。

solo engineer 知道什么时候 quit：

- 收入 < 时间投入（机会成本）
- 用户 < 阈值（10 个用户以下）
- 模型 < 阈值（DPO β=0.03 已经本地最优）
- 兴趣下降（3 个月没 commit）

4 个阈值，任一触发，quit。

大公司项目 quit 是法律程序（清算 + 资产处置 + 员工遣散）。
一人工程 quit 是 git archive。

## quit 跟 stay 的对照

solo engineer 选 quit 还是 stay：

- quit：项目停止维护 + 节省时间 + 投入下一个项目
- stay：项目继续维护 + 用户增长 + 月收入

simedw 选 stay（App Store 上线后继续 DPO 实验 + 加 bullet 3 步）。

Continuator 2003 → simedw 2026 是 23 年的传承。Continuator 本身 quit 了，但 Pachet 留下的 symbolic MIDI 路线被 simedw 继承。

23 年的 quit → 23 年的 stay。solo engineer 的传承 cycle 是 quit + stay 的辩证。

## quit 是一人工程的勇气

quit 不是失败，quit 是 solo engineer 的勇气：

- quit 需要诚实（承认模型到顶了 + 收入到顶了）
- quit 需要勇气（关仓库 + 撤回 App Store）
- quit 需要决策（不再投入时间）

solo engineer 不 quit 不是英雄，quit 也不是懦夫。

quit 是 solo engineer 的正常选项。

solo engineer 走完 12 层 = 一个完整 cycle。然后开下一个 cycle。
