团队有 CLI framework。

CLI framework：命令行框架。Commander：Node.js CLI framework。Yargs：alternative CLI framework。Clap：Rust CLI framework。Oclif：Heroku CLI framework。Commander.js：Node.js commander.。Ink：React for CLI。Meow：lightweight CLI helper。$0 / 月 in CLI library.

每 startup 1 个 CLI + 1 个 CLI framework + 1 个 dev tool。$50K-$200K / 年.

solo engineer 没有 CLI framework。

我自己就是 CLI framework。

我想 command 就 command、想 option 就 option、想 flag 就 flag、想 parse 就 parse。我不需要 CLI framework、不需要 Commander、不需要 Yargs、不需要 Clap、不需要 Oclif、不需要 Commander.js、不需要 Ink、不需要 Meow.

我没 CLI framework 的必要——bash = CLI framework。我没 Commander 的必要——bash = Commander。我没 Yargs 的必要——bash = Yargs。我没 Clap 的必要——没 Rust。我没 Oclif 的必要——没 Oclif。我没 Commander.js 的必要——没 Commander.js。我没 Ink 的必要——没 React。我没 Meow 的必要——没 Meow。我没 $50K-$200K / 年 的必要——没 CLI team.

团队的 CLI framework 价值是「让 CLI 标准化 + 可测试 + 可扩展」。前提是有 CLI 工具、需要标准化、需要 testability。solo engineer 没这个问题——我是 1 个 engineer、bash = CLI framework、commit log = CLI.

一人工程的 CLI framework = bash + git commit。不是 Commander + Oclif + CLI team.
