# Simon Edwardsson 一个人做完了一台机器

Simon Edwardsson 的项目就是「一人工程」的最干净版本。

不是「OpenAI 的小版本」。
不是「Anthropic 的简化版」。
是「一个人 + 一台机器 + 半年」的干净工程。

V7 招募 Simon Edwardsson。
Simon Edwardsson 做了：

- 125M transformer
- 14 次实验
- 半年训练
- INT8 量化
- iOS app RollTab
- MIT 协议 GitHub
- App Store 发布

加起来不到 50,000 行代码。
加起来不到 $10,000 总预算。
加起来不到 100 篇论文参考。

# 一人工程的清单

simedw（Simon Edwardsson）满足「一人工程」全部条件：

- 一个人
- 一个明确问题
- 一个标准架构
- 一个表征创新
- 一个训练目标
- 一个部署目标
- 一个开源
- 一个发布

每一项都是他自己做的。
不是团队。
不是公司。
不是股东。

# 一人工程的力量

LLM 时代最大的浪费是「没做完」。

simedw 做完了：

- 训练 → 训好
- 部署 → 上 iOS
- 评估 → 写论文
- 发布 → App Store
- 开源 → GitHub

每一件都做完。
不是「做到一半」。
不是「做 80%」。
是 100%。

# 一人工程的边界

simedw 不做：

- 100B 模型
- 几千万 GPU 小时
- 几百研究员
- 大模型时代的 LLM 训练

但这些不是「一人工程」的必要条件。
这些是「OpenAI」的必要条件。

simedw 的 64M 模型已足够「钢琴补全」。
simedw 的 iOS app 已足够「钢琴学习者」。
simedw 的 MIT 已足够「社区用」。

够了。

签名：solus opus。
