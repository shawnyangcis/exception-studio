团队有 SDLC。

SDLC：software development life cycle。Software development life cycle：软件开发生命周期。Waterfall：瀑布模型。V-model：V 模型。RAD：rapid application development。Spiral model：螺旋模型。Iterative：迭代。Requirements：需求。Design：设计。Implementation：实现。Testing：测试。Deployment：部署。Maintenance：维护。

每个 enterprise 1 个 SDLC framework + 1 个 process team + 1 个 compliance audit。$500K-$2M / 年。

solo engineer 没有 SDLC。

我自己就是 SDLC。

我想 commit = requirement。我想 design = commit message。我想 implement = commit code。我想 test = commit log。我想 deploy = Vercel。我想 maintain = next commit。SDLC 7 个 phase = commit log 7 个字段。我不需要 SDLC framework、不需要 waterfall、不需要 V-model、不需要 RAD、不需要 spiral。

我没 SDLC 的必要——没 enterprise compliance 要 follow。我没 software development life cycle 的必要——我是 cycle。我没 waterfall 的必要——我 = waterfall。我没 V-model 的必要——我 = V-model。我没 RAD 的必要——没 RAD。我没 spiral model 的必要——我 = spiral。我没 iterative 的必要——commit = iterative。我没 requirements 的必要——我 = requirement。我没 design 的必要——我 = design。我没 implementation 的必要——我 = implementation。我没 testing 的必要——我 = testing。我没 deployment 的必要——Vercel = deployment。我没 maintenance 的必要——commit = maintenance。我没 $500K-$2M / 年 的必要——没 process team。

团队的 SDLC 价值是「enterprise compliance + 流程标准化 + risk reduction」。前提是有 enterprise compliance、需要审计、需要标准化。solo engineer 没这个问题——没 enterprise compliance、commit log = compliance、我 = audit。

一人工程的 SDLC = commit log。不是 $500K process team。
