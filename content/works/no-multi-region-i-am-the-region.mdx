solo engineer 没有 multi-region。

大公司做 multi-region：

- **us-east-1 + us-west-2 + eu-west-1 + ap-southeast-1**：4+ 个 region
- **跨 region replication**：database / storage / config 跨 region 同步
- **Route 53 latency-based routing**：根据用户位置路由到最近的 region
- **跨 region failover**：us-east-1 down → 自动 failover 到 us-west-2
- **active-active**：所有 region 同时服务
- **active-passive**：us-east-1 主 + us-west-2 备份

一人工程做 multi-region：
- 没有跨 region replication
- 没有 Route 53
- 没有跨 region failover
- 没有 active-active / active-passive

## simedw 的 multi-region 哲学

simedw 是 iPhone piano app。他没有 multi-region：

- **simedw 没有 server**：iPhone app 本地运行，没有 region
- **simedw 的 app 全球分布**：每个用户的 iPhone = 一个 "region"，100 用户 = 100 个 "region"
- **simedw 没有跨 region 同步**：iPhone app 状态在用户 iPhone 本地，不需要跨 region 同步
- **simedw 没有跨 region failover**：iPhone app 本地运行，不会"down"
- **simedw 没有 latency routing**：iPhone app 没有网络延迟

simedw 的"multi-region"在苹果 App Store + iPhone OS：

- **App Store 全球分发**：苹果在 175+ 国家分发
- **iPhone 本地运行**：每个 iPhone 独立处理请求
- **iPhone OS 自动更新**：用户 iPhone 自动下载新版本
- **iPhone 离线可用**：iPhone app 没有网络也可用

不需要 AWS multi-region，因为：
- simedw 没有 server
- iPhone app 本地运行 = 0 网络依赖
- 每个 iPhone = 全球分布的"region"

## 跨 region failover 在大公司的细节

大公司跨 region failover：

- **us-east-1 down → us-west-2**：primary down → 自动切到 backup
- **RPO** (Recovery Point Objective)：最多丢失 X 分钟数据
- **RTO** (Recovery Time Objective)：最多 X 分钟恢复
- **RPO = 0**：zero data loss（同步复制）
- **RTO = 0**：zero downtime（active-active）

每个跨 region failover：

- 几小时到几天配置
- $XXX,XXX / 月成本（双 region 资源）
- 5 个 SRE 维护

一人工程没有跨 region failover。一人工程有：

- **simedw iPhone app 不能 down**：iPhone app 本地运行，永远能打开
- **simedw 不需要 RPO / RTO**：iPhone app 没有数据丢失
- **simedw 不需要双 region**：iPhone app 没有 region 成本

## active-active vs active-passive 在大公司的细节

大公司 active-active vs active-passive：

- **active-active**：所有 region 同时服务（每个 region 接收 1/N 流量）
  - 优点：零 downtime（一个 region down，其他 region 继续服务）
  - 缺点：成本 2x（双 region 资源）
- **active-passive**：primary region 服务 + backup region 待机
  - 优点：成本 1.x（backup 不接流量）
  - 缺点：primary down → failover 时间（几秒到几分钟）

一人工程没有 active-active vs active-passive。一人工程有：

- **simedw 100 个 iPhone = active-active**：100 个 iPhone 同时服务（每个用户独立）
- **simedw 没有 backup**：iPhone app 不需要 backup region（本地运行）
- **simedw 0 成本**：iPhone app 没有 region 成本
