- 质量直接评

这是「拒绝包装」。

# OpenAI 的包装哲学

OpenAI 论文的 Limitations 段：

- 「可能存在偏见」
- 「未来工作包括 X、Y、Z」
- 「还需要进一步研究」
- 「本模型不是 AGI」

OpenAI 的 framing：

- 「人类水平」
- 「专业级」
- 「企业级」
- 「AGI 前夜」

OpenAI 的 failure 写法：

- 「存在局限」
- 「可以改进」
- 「we leave this for future work」

每个失败都被包装成「限制」。
每个限制都指向 future work。
每个 future work 都暗示「还要更好」。

包装 = 不直面失败。
包装 = 让用户觉得「还不够」。
包装 = 让投资人觉得「还有空间」。

# simedw 的反包装

simedw 写失败：

> 「note-on/note-off 表征飘音」 ← 一行
> 「grammar-masked 慢」 ← 一行
> 「Born-again networks 没用」 ← 一行

每行就是一行。
没有「but we found it interesting」。
没有「we leave this for future work」。
没有「可能存在偏见」。

simedw 写质量自评：

> 「GPT-2 level, good enough to share, but with a lot of room left to improve.」

直接说 GPT-2 级。
不假装 GPT-4。
不假装 GPT-5。
不假装 AGI。

simedw 写论文姿态：

> 「deliberately haven't read a lot of papers, would rather do my own thing first and then compare against literature afterwards.」

直接说「故意没读太多论文」。
不假装「读完所有文献」。
不假装「站在巨人肩膀上」。

simedw 写产品类比：

> 「Copilot for piano, like GitHub Copilot but for piano.」

直接借用 GitHub Copilot 类比。
不假装「革命性发明」。
不假装「全新范式」。

# 一人工程的反包装

simedw 的反包装不是「故意」。

是「只能」：

- 一个人没时间写 Limitations 段
- 一个人没 budget 做 future work 包装
- 一个人没 marketing team 制造 framing
- 一个人不假装自己是大公司

反包装是「一人工程的自然状态」：

- 没包装预算
- 没包装时间
- 没包装人员
- 直接写就行

# 包装 vs 反包装

| 维度 | OpenAI 包装 | simedw 反包装 |
| --- | --- | --- |
| 失败写法 | Limitations + future work | 「没用」「慢」「飘」 |
| 质量自评 | 「人类水平」 | 「GPT-2 级」 |
| 论文姿态 | 「站在巨人肩膀」 | 「故意没读太多」 |
| 产品类比 | 「革命性发明」 | 「Copilot for piano」 |
| AGI framing | 「AGI 前夜」 | 不假装 AGI |
| 隐含意图 | 让用户期待更多 | 让用户知道边界 |

# 反包装的价值

simedw 的反包装给用户：

- 准确预期（GPT-2 级 = GPT-2 级）
- 真实边界（哪些没用）
- 真实方法（故意没读太多论文）

OpenAI 的包装给用户：

- 膨胀预期（AGI 前夜 = 期待 AGI）
- 虚假边界（future work = 假装还有提升空间）
- 虚假方法（站在巨人肩膀 = 假装知识完备）

simedw 用户满意（符合预期）。
OpenAI 用户失望（不符合预期）。
