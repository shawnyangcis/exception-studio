团队有 code review。

Code review：代码评审。Pull request review：PR 评审。Peer review：同行评审。PR review：PR 评审。Gerrit：Google code review tool.。Phabricator：Facebook code review tool.。Crucible：Atlassian code review.。LGTM：looks good to me.。Review bot：自动 review bot.。$0-$100 / 月 in review tool.

每 startup 1 个 code review + 1 个 PR review + 1 个 peer review + 1 个 senior engineer + 1 个 review team.。$200K-$500K / 年.

solo engineer 没有 code review。

我自己就是 code review。

我想 review 就 review、想 approve 就 approve、想 comment 就 comment、想 merge 就 merge.。我不需要 code review、不需要 pull request review、不需要 peer review、不需要 PR review、不需要 Gerrit、不需要 Phabricator、不需要 Crucible、不需要 LGTM、不需要 review bot.。

我没 code review 的必要——我是 1 个 engineer 我自己 review。我没 pull request review 的必要——main = merged code。我没 peer review 的必要——没 peer。我没 PR review 的必要——commit log = PR review。我没 Gerrit 的必要——没 Gerrit。我没 Phabricator 的必要——没 Phabricator。我没 Crucible 的必要——没 Crucible。我没 LGTM 的必要——commit = LGTM。我没 review bot. 的必要——commit log = bot。我没 $0-$100 / 月 的必要——Vercel free + git。我没 senior engineer 的必要——没 senior engineer。我没 review team 的必要——没 review team。我没 $200K-$500K / 年 的必要——没 review infrastructure.

团队的 code review 价值是「让 code 质量 + 知识共享 + 防止 bug」。前提是有 multi-developer、需要 quality、需要 knowledge sharing。solo engineer 没这个问题——访问量 1000、commit log 是 review、我我 = quality.

一人工程的 code review = git commit + diff self-review。不是 PR review + senior engineer + review team. .
