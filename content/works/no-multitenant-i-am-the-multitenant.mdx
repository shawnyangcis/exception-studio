团队有 multi-tenant。

Multi-tenant：多租户。SaaS：software as a service。Tenant isolation：租户隔离。Database per tenant：每租户一数据库。Schema per tenant：每租户一 schema。Row-level security：行级安全。$50-$1000 / 月 in multi-tenant infrastructure.

每 SaaS 1 个 multi-tenant + 1 个 tenant isolation + 1 个 data team。$200K-$500K / 年.

solo engineer 没有 multi-tenant。

我自己就是 multi-tenant。

我想 isolate 就 isolate、想 tenant 就 tenant、想 partition 就 partition、想 secure 就 secure。我不需要 multi-tenant、不需要 SaaS、不需要 tenant isolation、不需要 database per tenant、不需要 schema per tenant、不需要 row-level security.

我没 multi-tenant 的必要——访问量 1000 不需要 tenant。我没 SaaS 的必要——没 SaaS。我没 tenant isolation 的必要——没 tenant。我没 database per tenant 的必要——commit log = database。我没 schema per tenant 的必要——没 schema。我没 row-level security 的必要——没 row-level security。我没 $50-$1000 / 月 的必要——Vercel free + commit log。我没 data team 的必要——没 data team。我没 $200K-$500K / 年 的必要——没 multi-tenant infrastructure.

团队的 multi-tenant 价值是「让多个 customer 共享 infrastructure + 减少 cost + 规模化」。前提是有 multi-customer、需要 cost efficiency、需要 scale。solo engineer 没这个问题——访问量 1000、commit log = multi-tenant、我 = scale.

一人工程的 multi-tenant = Next.js + git commit。不是 database per tenant + SaaS $1000/月 + data team.
