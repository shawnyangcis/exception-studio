团队有 objectives。

Objectives：目标。OKR：objectives + key results。KPI：key performance indicator。Goals：goals。Mission：使命。Vision：愿景。SMART goals：specific / measurable / achievable / relevant / time-bound。Goal setting：设定目标。Goal tracking：跟踪目标。$200-$500 / 月每人 in goal software。

每 startup 1 个 goal-setting process + 1 个 Lattice / 15Five / BetterWorks。$50K-$200K / 年。

solo engineer 没有 objectives。

我自己就是 objective。

我想写什么就写什么、我想 commit 什么就 commit 什么、我想做什么就做什么。我不需要 objectives、不需要 OKR、不需要 KPI、不需要 SMART goals。

我没 objectives 的必要——我没 manager 要 align。我没 OKR 的必要——commit log 是 OKR。我没 KPI 的必要——commit 数 = KPI。我没 goals 的必要——commit = goal。我没 mission 的必要——我 = mission。我没 vision 的必要——我 = vision。我没 SMART goals 的必要——commit 是 SMART。我没 goal setting 的必要——我 = setter。我没 goal tracking 的必要——commit log 是 tracking。我没 $200-$500 / 月 的必要——Vercel free。

团队的 objectives 价值是「让员工知道方向 + 衡量进度 + 协调」。前提是有员工、需要 alignment、需要 measurement。solo engineer 没这个问题——没员工、不需要 alignment、commit log = measurement。

一人工程的 objectives = commit log。不是 $200/月 Lattice。
