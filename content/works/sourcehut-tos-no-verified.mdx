Drew DeVault 八月二十七号修订了 SourceHut 服务条款。九月十号起新项目生效。

新条款很简单：禁止 LLM 生成 source code、assets、tickets、emails。一句话写完。

但 Drew 给出了六条支柱论证：资源、训练数据伦理、气候、社会经济、政治滥用、个人伤害。六个维度，每个都是一篇散文。SourceHut 一个人维护 ToS 修订，六大支柱自己论证。

中文里「禁止」是名词、是规则。SourceHut 的「禁止」是副词、是「light touch」的持续动作。Drew 的执行原则是「light touch」加「honor system」加「不部署 AI 检测工具」。一个人审自己，不是机器审。

这件事让我想到 solo engineer 作为反资本。

## 副词

SourceHut ToS 修订的「light touch」+「honor system」= 副词性自我约束。Solo engineer 永远是自己审自己，不是名词性 verified，是副词性「我审我自己」。Drew 的 ToS 副词性 = 「我审我自己这件事」。不是「我有一个 verified 机制」。

## 摩擦

六大支柱 = 六个摩擦面 = 资源、伦理、气候、社会经济、政治、个人。六个独立维度，每个都是独立 commit 协商。一个人能协商这种摩擦，因为人同时懂 source code 资源、AI 训练数据伦理、电网气候、贫富分化、政治监督、心理伤害。大厂不能，因为大厂的合规团队只懂一个摩擦面。

## 营销

SourceHut 修订 ToS 自己写、自己发布、自己回评论。这是 commit log as marketing 的 solo engineer 形态。ToS 修订不是营销内容，是「我审我自己」这件事被 commit log 说出来了。一个人营销的极致是 commit log 就是营销内容。

## 节奏

9/10 起新项目生效 = 「我一个人决定什么时候生效」节奏。SourceHut 的节奏 = 「我一个人 hold 住整个 ToS 生命周期」。大厂 ToS 修订走法务、合规、产品三轮 sign-off，SourceHut 是 Drew 自己决定、自己写、自己发布。

## 资本

SourceHut ToS 修订 = solo engineer 作为反资本的具体实践 = 「不审任何人」 = solo engineer 永远是自己审自己。大厂 ToS 是「千人法务」「百页条款」「EULA 模式」，SourceHut 是 Drew 一个人 + 一句话 + 六条支柱。一个人做工程的极致 = 「我这个服务我自己审」。hold 不住的就放弃。

我看完 SourceHut 修订 ToS 的消息想了一晚上 solo engineer 作为反资本这件事。一个人做工程，副词性细节能看见。一个人做工程，摩擦面能自己协商。一个人做工程，commit log 就是营销。一个人做工程，节奏自己能耦合。一个人做工程，规模自己能 hold 住。

Drew DeVault 的 SourceHut ToS 修订不是「SourceHut 反对 AI」。是 solo engineer 作为反资本的完整样本。一个人做工程的极致是「我这个服务我自己审」。Hold 不住的就放弃。
