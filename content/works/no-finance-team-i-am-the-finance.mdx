团队有 finance team。

Finance team：CFO + controller + accountant + AR/AP。Controller：每月关账、做 journal entry。Accountant：GAAP / IFRS 报表。Tax：报税 + compliance。Audit：外部审计师 audit 财务。Financial reporting：10-Q / 10-K。

5-10 个人 finance team = $500K-$1M / 年。

solo engineer 没有 finance team。

我自己就是 finance。

我自己管钱（Vercel $20/月 + 域名 $12/年 + 咖啡 + 一台电脑）。我自己交税（IRS Schedule C / 1040）。我自己记账（Google Sheet）。我自己报账（自己看 GitHub Sponsors / Stripe dashboard）。

我没 CFO 的必要——我 = CFO。我没 controller 的必要——没 journal entry。我没 accountant 的必要——没 GAAP 报表。我没 tax 的必要——没公司报税。我没 audit 的必要——没 external auditor。我没 10-Q / 10-K 的必要——没 SEC 报表。

团队的 finance team 价值是「管理公司财务 + 合规 + 报告」。前提是公司大、需要 GAAP / SEC 合规、需要复杂 financial ops。solo engineer 没这个问题——我 = 1 人公司、没 GAAP、没 SEC、没复杂 ops。

一人工程的 finance = Google Sheet + Schedule C。不是 5-10 个人 $500K / 年。
