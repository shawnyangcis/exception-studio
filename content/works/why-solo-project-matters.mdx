# 为什么 solo project 重要

solo project 不是「一个人做小东西」。
是「一个人做完一件大事」。

「小东西」+「一个人」≠ solo project
「大东西」+「一个人」= solo project

simedw 一个人做完了一台机器 + iOS app + GitHub README + 14 次实验 + 半年。

这是 solo project 的现代意义。

# 旧时代 solo project

2010 年代 solo project：

- 个人博客
- 个人 app
- 个人游戏
- 个人网站

特点：

- 小
- 单文件
- 一周完成
- 没有部署压力

新时代 solo project（2020s+）：

- 训练 ML 模型
- 部署 iOS app
- 开源 GitHub
- MIT 协议
- 半年到一年

特点：

- 大
- 多模块
- 长期
- 有部署压力

# 为什么 solo project 重要

不是「小而美」。
是「大而独」。

「大」：

- 125M 模型
- iOS app
- 半年时间
- 14 次实验

「独」：

- 一个人做
- 没有团队
- 没有公司
- 没有股东

「大 + 独」= solo project = 「一人工程」

# 旧时代的 solo project 没做完的事

个人博客 = 没做完（没收入）
个人 app = 没做完（没下载）
个人游戏 = 没做完（没发布）
个人网站 = 没做完（没流量）

新时代 solo project 做完的事：

- simedw iOS app = 做完（App Store 上）
- AprilNEA OpenLogi = 做完（GitHub master）
- turbovec = 做完（PyPI）
- yassa9 = 做完（Micronesia resort）
- linecam = 做完（列车窗胶带相机）

每一件都是「做完」。
不是「做 80%」。

签名：solus opus。
