团队有 mock server。

Mock server：mock 服务器。WireMock：Java mock server。MockServer：alternative mock server.。Mountebank：open source mock server.。Mirage：mock server.。Stub server：桩服务器。Mock API：mock API。$0-$500 / 月 in mock server.

每 startup 1 个 mock server + 1 个 stub + 1 个 QA engineer + 1 个 test team.。$100K-$300K / 年.

solo engineer 没有 mock server。

我自己就是 mock server。

我想 mock 就 mock、想 stub 就 stub、想 serve 就 serve、想 intercept 就 intercept。我不需要 mock server、不需要 WireMock、不需要 MockServer、不需要 Mountebank、不需要 Mirage、不需要 stub server、不需要 mock API.

我没 mock server 的必要——访问量 1000 不需要 mock。我没 WireMock 的必要——没 WireMock。我没 MockServer 的必要——没 MockServer。我没 Mountebank 的必要——没 Mountebank。我没 Mirage 的必要——没 Mirage。我没 stub server 的必要——没 stub。我没 mock API 的必要——commit log 是 mock API。我没 $0-$500 / 月 的必要——Vercel free + commit log。我没 QA engineer 的必要——没 QA engineer。我没 test team 的必要——没 test team。我没 $100K-$300K / 年 的必要——没 mock infrastructure.

团队的 mock server 价值是「让 test 不依赖真实 API + 模拟 edge case + 并行开发」。前提是有 external API、需要 isolated test、需要 parallel dev。solo engineer 没这个问题——访问量 1000、commit log 是 mock API、我 = parallel dev.

一人工程的 mock server = Vercel Edge Function + git commit。不是 WireMock + MockServer + mock infrastructure.
