# 一人 GitHub 主页

simedw 的 GitHub 主页：

- github.com/simedw
- README 完整
- MIT 协议
- 可运行代码
- 14 次实验
- 一个 iOS app

个人 GitHub 主页能做到的最强版本。

不是「个人博客」。

个人博客：

- 文章
- 评论
- 广告
- 平台依赖

个人 GitHub 主页：

- 代码
- 数据
- 训练脚本
- 部署脚本
- 评估脚本
- 一次性 install + 跑通

# 一人 GitHub 主页的特征

- README 第一版（github-readme-first-version）
- MIT 协议
- 可 pip install
- 可 python -m xxx.train
- 可 rollout 听
- 可部署到 iOS

每一个 step 都是可复现的。
不是「模拟结果」。
是「真实跑通」。

# 一人工程的现代版本

simedw 的 GitHub 主页是「一人工程」的现代版本：

- 个人代码
- 个人训练
- 个人部署
- 个人发布
- 个人 GitHub

不是「个人博客 + 个人 LinkedIn + 个人 Twitter」。

是一个人 + 一台机器 + 一个 GitHub + 一个 App Store + 一个 iOS app。

OpenAI 不会做「一人 GitHub」。
simedw 会。

# 一人工程的意义

个人 GitHub 主页是 21 世纪的「个人简历」。
比 LinkedIn 强：

- 真实代码
- 真实运行
- 真实数据
- 真实部署

比 Twitter 强：

- 没有 280 字限制
- 没有 PR review
- 没有会议日程

比 Medium 强：

- 不靠广告
- 不靠订阅
- 不靠 SEO

签名：solus opus。
