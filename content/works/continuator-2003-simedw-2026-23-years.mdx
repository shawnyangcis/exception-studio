François Pachet 2003 年在 Sony CSL Paris 做了 Continuator。

23 年后，Simon Edwardsson 2026 年在 iPhone App Store 发了 midi-autocomplete。

23 年 = 同一条 symbolic MIDI 路线。

## Continuator 是什么

Continuator = 钢琴家按下几个音 + 钢琴自动续写 + 续写风格匹配演奏者 = 实时音乐对话。

2003 年没人做 AI 音乐 app。Continuator 是最早的 AI 钢琴补全 demo。

Pachet 2003 年用的方法：symbolic MIDI 输入 + Markov chain + 风格匹配。

## simedw 是什么

midi-autocomplete = 钢琴家按下几个音 + iPhone 续写下一个 note + 续写风格匹配演奏者 = 实时音乐对话。

2026 年 Apple App Store Music 类目。125M MIDI transformer + DPO β=0.03 + Core ML + iPhone 部署。

simedw 用的方法：symbolic MIDI 输入 + Transformer + DPO 偏好对齐 + 端侧部署。

## 23 年同一条线

Continuator 2003：
- symbolic MIDI input
- Markov chain
- 实时续写
- 风格匹配

simedw 2026：
- symbolic MIDI input
- Transformer
- 实时续写
- 风格匹配

4 个抽象一致。23 年技术换了（Markov → Transformer），4 个抽象不变。

这就是 symbolic MIDI 路线的传承：技术换代，抽象层不变。

## 一人工程的传承

Continuator 是 Sony CSL Paris 的研究项目。Pachet 是 Sony 研究员。

simedw 是 V7 contractor。V7 不是 Apple / Google / OpenAI。

两个项目都不是大公司项目。都是 solo engineer（或小团队）。

solo engineer 继承 solo engineer，不靠 research lab。

Pachet 2003 的 symbolic MIDI 路线被 simedw 2026 继承：

- 不被 Stanford 蒸馏（Stanford 走 multi-track large model）
- 不被 Magenta 蒸馏（Magenta 走 audio level）
- 不被 Anthropic 蒸馏（Anthropic 不做 music）
- 被 solo engineer 继承

这是 solo engineer 生态系统的传承机制——不是论文引用，而是项目接力。

## 23 年间隔的意义

23 年 = 一代人。

2003 年 Pachet 30 岁。2026 年 simedw 应该是 20+ 岁。

23 年后另一个 solo engineer 接力。Solo engineer 跟 solo engineer 之间的传承比 research lab 之间的传承更慢、更深、更稳定。

Solo engineer 传承靠 README + GitHub + HN show，不是靠 paper + citation。

## 一人工程的传承 cycle

solo engineer 的传承 cycle：

- 项目 1：solo engineer A 写完，留 README + HN show
- 项目 2：solo engineer B 读 README + HN show，继承项目 1 的 framing
- 项目 3：solo engineer C 继承项目 2 的 framing + 项目 1 的失败记录

3 代 solo engineer 走完一个传承 cycle。

Continuator 2003 → simedw 2026 是 23 年传承 cycle。下次传承 cycle 可能是 2030+ 年。
