团队有 Tailwind。

Tailwind：utility-first CSS。Bootstrap：传统 CSS framework。Chakra：React UI library。MUI：Material UI。styled-components：CSS-in-JS。Emotion：CSS-in-JS。CSS modules：scoped CSS。$0 / 月 in open source CSS.

每 startup 1 个 Tailwind + 1 个 design system + 1 个 frontend engineer。$200K-$500K / 年。

solo engineer 没有 Tailwind。

我自己就是 CSS。

我想 style 就 style、想 theme 就 theme、想 responsive 就 responsive、想 dark mode 就 dark mode。我不需要 Tailwind、不需要 Bootstrap、不需要 Chakra、不需要 MUI。

我没 Tailwind 的必要——我是 1 个 engineer 我写 CSS。我没 Bootstrap 的必要——没 Bootstrap。我没 Chakra 的必要——没 React UI library。我没 MUI 的必要——没 Material UI。我没 styled-components 的必要——没 CSS-in-JS。我没 Emotion 的必要——没 Emotion。我没 CSS modules 的必要——我 = CSS module。我没 design system 的必要——commit log = design system。我没 frontend engineer 的必要——我自己 frontend。我没 $200K-$500K / 年 的必要——没 design system。

团队的 Tailwind 价值是「让 CSS 标准化 + 提高 productivity」。前提是有 frontend team、需要 CSS standardization、需要 productivity。solo engineer 没这个问题——我是 1 个 frontend engineer、Tailwind 我选、commit = productivity。

一人工程的 CSS = Tailwind + commit log。不是 Bootstrap + 5 个 frontend engineer。
