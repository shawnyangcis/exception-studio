# Mirostat 减重复但紊乱

> simedw 的失败实验笔记：
> Mirostat v2 减重复但紊乱。
> 最终没采用。
> 在「没走通的」一栏。

Mirostat v2 是什么：

- 采样算法
- 不直接减 top-k/top-p
- 而是用 surprisal 作为控制信号
- 维持 surprise 期望稳定

直觉：

> 感觉重复了 → 调高 surprise 阈值
> 感觉跑偏了 → 调低 surprise 阈值

simedw 试了：

- 减重复效果：可以
- 但 MIDI 听起来「杂乱」

为什么紊乱：

- 钢琴需要稳定的节拍与和声
- Mirostat 的 surprisal 调控会让钢琴走「不稳」的路线
- 重复减了，但风格破坏

对比 top-p：

- top-p 直接砍概率分布的低尾
- 保持 MIDI 的和声走向
- 重复还是会，但风格不破坏

simedw 的选择：

- top-p / top-k / min-p / XTC / top-h 都进了产品
- Mirostat v2 留在「没走通的」一栏
