# 一个人 + 一台机器

> simedw 的工作条件：
> 一个人，一台机器，一组 GPU 跑半年。
> V7 招募他做这个事，但他一个人做完了一台机器就能跑 GPT-2 级钢琴补全。

simedw 的资源：

- 一个人（Simon Edwardsson）
- 一台机器（4 × RTX 4090）
- 半年时间
- iPhone 15 做部署目标

OpenAI 的资源：

- 几百研究员
- 几万台 H100 / A100
- 几年
- 整个数据中心做训练

但产出：

- OpenAI 的 ChatGPT 是「聊天 + 补全」的混合
- simedw 的 RollTab 是「钢琴 + 补全」的专项

规模：

- ChatGPT 100B+ 参数
- RollTab 64M 参数（量化后 25 MB）

但用户价值：

- ChatGPT 用户：百万级
- RollTab 用户：iOS 钢琴学习者

不同的规模，不同的价值。

## V7 的角色

simedw 是被 V7 招募的。
V7 = Vision 7，一家 AI 招募公司。

V7 给 simedw 提供了什么？

- 工资
- 协作平台
- 品牌曝光
- 也许一点点算力

simedw 给 V7 提供了什么？

- 一个能展示的 AI 故事
- 一个能进 iOS App Store 的产品
- 「AI for music」的样例

交易：

> V7 给资源，simedw 给作品。

但 simedw 不是 V7 的雇员——他是 contractor。
独立承包，独立发布，独立 GitHub 主页，独立 iOS app。
不是 V7 的产品，是 simedw 的产品。

# 一人工程的现代版本

不是「一个人单打独斗」。
是「一个人 + 一个招募公司 + 一个开源社区 + 一个苹果 App Store」。

资源从四面八方来：

- 工资：V7
- 算力：4 × RTX 4090（自己买或公司配）
- 协作：GitHub Issues + PR
- 部署：苹果 App Store

simedw 不需要 OpenAI 的研究栈。
他需要的是：

- 一台能跑 transformer 的机器
- 一个能上 iOS 的渠道
- 一个能让他写 + 训 + 部署 + 上线的环境

# 一人工程的边界

资源够用：

- 64M 模型训练一周
- INT8 量化到 25 MB
- iPhone 15 跑 108 notes/sec
- 上 App Store

一个人可以做。
但需要：

- 一台好机器（4090 不是必需的，但慢 CPU 不行）
- 一个苹果开发者账号（$99/年）
- 一些常识（PyTorch、Core ML、App Store 流程）

这些都不是「OpenAI 的资源」。
是「现代开发者能搞到的资源」。

签名：solus opus。
