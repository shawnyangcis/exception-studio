# V7 contractor 不是 V7 雇员

> simedw 的 simedw.com 页脚：
> 「Like what you see? We're hiring at V7! Join our team working on the future of AI.」

simedw 不是 V7 雇员。
他是 contractor。

V7 是 Vision 7，一家 AI 招募公司。
V7 通过 simedw 展示 AI 能力。
simedw 在 V7 招聘页上挂着自己的应用。

关系：

- V7 → 工资
- simedw → 产品
- 不是雇佣关系
- 是 contractor 关系

# contractor vs employee

employee：

- 受雇于公司
- 工作成果归公司
- 不能在外部发表
- 不能用公司名义做 side project

contractor：

- 独立承包
- 工作成果归自己
- 能在外部发表
- 能用自己名义做 side project

simedw 是后者：

- GitHub 上的 simedw/midi-autocomplete 是他的
- iOS 上的 RollTab 是他的
- simedw.com 是他的
- V7 招聘链接 bit.ly/4kzLOtH 在他博客上挂着

# 一人工程 vs 大公司

OpenAI 雇员：

- 受雇于 OpenAI
- 工作成果归 OpenAI
- 不能在外面发布 GPT-4
- OpenAI 是他们的雇主

simedw：

- 不是 V7 雇员
- 工作成果归自己
- 能在外面发布 RollTab
- V7 只是 contractor 客户

# 一人工程的现代版本

不是「不要公司」。
是「用 contractor 模式」。

simedw 拿一份工资 + 自己做所有产品。
V7 拿一个 AI 故事 + 不需要养全职团队。

双赢：

- simedw：稳定工资 + 自由产品
- V7：AI 故事 + 不养团队

比 employee 更自由。
比 freelancing 更稳定。

# 一人工程的边界

simedw 的 contractor 关系：

- 工资可能比 OpenAI 低
- 不享受 OpenAI 的算力
- 不参与 OpenAI 的内部研究
- 但能做自己想做的产品

trade-off：

- 工资低
- 自由高
- 产品自留
- 故事自写

签名：solus opus。
