团队有 onboarding flow。

User onboarding flow：用户引导流程。Activation funnel：激活漏斗。FTUE：first-time user experience。Product tour：产品 tour。Walkthrough：walkthrough。Welcome email：欢迎邮件。Tooltip：提示。Checklist：checklist。$50-$200 / 月 in onboarding tool。

每 SaaS 1 个 onboarding tool + 1 个 growth team。$100K-$300K / 年。

solo engineer 没有 onboarding flow。

我自己 commit。

我 commit 散文 = onboarding。访问者点开看 = activation。我不需要 product tour、不需要 walkthrough、不需要 tooltip、不需要 checklist。

我没 user onboarding flow 的必要——访问者自己看散文。我没 activation funnel 的必要——commit = funnel。我没 FTUE 的必要——first time = first commit。我没 product tour 的必要——散文 = tour。我没 walkthrough 的必要——散文 = walkthrough。我没 welcome email 的必要——没 email 收集。我没 tooltip 的必要——散文没 tooltip。我没 checklist 的必要——commit = checklist。我没 $50-$200 / 月 的必要——Vercel free。

团队的 onboarding flow 价值是「让 user 快速 reach activation + 减少 churn」。前提是有 user、需要 activation、需要 FTUE 测试。solo engineer 没这个问题——访问者自己看、commit log = activation、散文 = FTUE。

一人工程的 onboarding flow = commit log + 散文。不是 Appcues $200/月。
