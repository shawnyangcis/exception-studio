# 一人工程

一个人能搞定的事。

## 三个算

- 一个人能搞定的事。
- 不是 1% 进步的事。
- 是不开后漏风的事。

## 三个例子

- turbovec 一个人两个月，从 0 写到比 FAISS IndexPQFastScan 快 3.4×。
- yassa9 一个 GPU runner 三角化到 Micronesia Oan resort，北纬 7.363444°，东经 151.755750°。
- linecam 一个人胶带把相机粘在列车窗上，列车的地板是加速计。

## 三个不算

- 一个人不能搞定的事——比如把 GPT-5 训到 SOTA。
- 一个人不该独自搞定的事——比如修一座桥。
- 一个人假装独自搞定的事——比如 share count 0 但在 5 个 GitHub 账户间互换贡献。

## 准则

不动声色地做完。
开后漏风的时间，0。
PR review 的时间，0。
会议日程，0。
Slack 通知，0。

写下来，可复现，已 push。

## 名字

中文：一人工程。
英文：One-Man Project。
签名：solus opus。
