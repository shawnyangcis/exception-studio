## 「I want to see bytes」哲学

所有 7 个项目共同的核心哲学 = 「**I want to see bytes**」。

字节是二进制的最小单位。文本编辑器显示 ASCII，hex editor 显示 hex，但二进制文件不是 ASCII 也不是 hex —— 二进制文件是「**一堆看起来没有意义的字节**」。

Visualizing binary files = 把这堆字节**可视化**为有意义的图像。

| 项目 | 可视化方法 |
|------|----------|
| bin-graph | 把字节映射为 PNG/SVG 像素 |
| binvis.io | 在网页上把字节映射为色块 |
| Rizin `V` | 在 terminal 里把字节映射为彩色块 |
| ImHex pattern | 把字节按 DSL pattern 解析 |
| Veles | 把字节映射为可缩放的彩色块 |

**所有方法的共同点**：**让字节变得可读、可识别、可理解**。

## movq 哲学：hex editor 是哲学不是工具

movq.de 2026-08-05 blog post「Visualizing binary files」不是技术教程，是**hex editor 哲学**。

movq 的论点：
- hex editor 不是「显示字节的工具」
- hex editor 是「理解字节的窗口」
- 不同的 hex editor 提供不同的「理解窗口」
- 选择 hex editor = 选择「如何理解字节」

- MDX 是「理解散文的窗口」

- 选择 MDX 渲染器 = 选择「如何理解散文」

## ImHex pattern language DSL

ImHex = WerWolv 的开源 hex editor，特色是 **pattern language** —— 一种 DSL 用来描述二进制格式。

比如你可以写一个 ImHex pattern 来解析 PNG 文件：
```
struct PNGHeader {
    u32 magic;  // 0x89504E47
    u32 width;
    u32 height;
    u8 bit_depth;
    u8 color_type;
    // ...
};
```

ImHex 会把这个 pattern 应用到 PNG 文件，自动高亮对应的字节。
