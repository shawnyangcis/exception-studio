团队有 onboarding。

Onboarding：新员工入职。First day：HR 接、电脑装、welcome dinner。First week：5 个 1-on-1 介绍 + 5 个 meeting。Ramp up：3 个月到 productivity。Buddy system：老员工带新员工。Onboarding doc：100 页 wiki。

每个新员工 onboarding = $5K + 3 个月 ramp up。

solo engineer 没有 onboarding。

我自己 onboarding。

我自己接手自己的项目 = onboarding。我不需要 first day、不需要 HR、不需要电脑、不需要 welcome dinner、不需要 5 个 1-on-1、不需要 ramp up。

我没 onboarding 的必要——没 new hire。我没 first day 的必要——没 first day。我没 ramp up 的必要——我立刻 productivity。我没 buddy 的必要——没 buddy。我没 onboarding doc 的必要——commit log = onboarding。

团队的 onboarding 价值是「让新员工快速融入 + productivity」。前提是有新员工、需要 ramp up、需要 culture。solo engineer 没这个问题——没 new hire、不需要 ramp up、commit log 是 culture。

一人工程的 onboarding = git clone + git log。不是 $5K + 3 个月。
