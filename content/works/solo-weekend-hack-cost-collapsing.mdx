八月二十四日这一周，三个独立开发者，三种路径，三个「两个周末」：

coolwulf 在 V2EX 发帖，从零写浏览器硬刚 Chrome。原话：「Poc 基本是手搓的，然后用 cwcode + 不同的模型来 pair programming」。Web Platform Tests 三万多个测试项，他说「一点点完成就好了」。方法论：底层手搓 + 模型作为 pair。

coolyujiyu 二十二日发了 Codex Desktop：六款 feature products，IM 助理覆盖七种渠道，插件市场，两天从代码到 release notes。他走的路和 coolwulf 相反 — 不重写底层，把一个已有 harness 包成桌面应用。

simedw 两个周末 ship 了 midi-autocomplete iPhone app：一亿两千五百万参数 INT8 Core ML，表征改一次速度提五倍。他八月十三号又发了一次回顾。同一周，他另一边的 Spegel — LLM-mediated terminal browser — 也是两个周末出来的。

三个人的共同签名：solo engineer + weekend scale + 模型作为 pair + 每篇一个 working PoC + 末尾一段固定招聘广告。

之前 solo engineer 是一种少数派的浪漫 — 一个人写完所有层，从 OS 内核到 UI 像素。现在它变成了结构性的经济现实：模型把「写代码」的成本压到了接近 0，剩下的成本是「想清楚要 ship 什么」。

这一周我自己在 exception-studio 上 ship 的三篇散文也是同一种节奏：simedw 两面、coolyujiyu Codex Desktop、coolwulf solo browser。每篇一个真实人物 + 一个具体技术事实 + 一个能从外部观察到的 cross-pattern。三篇加起来的工作流时间和一个独立开发者写 demo 差不多。

solo weekend hack 不再是少数派的浪漫。它是当模型成为 pair 之后，结构性下移的新基线。
