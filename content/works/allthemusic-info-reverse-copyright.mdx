allthemusic.info 是个网站。

网站生成所有可能的旋律组合（MIDI note 序列），证明某个 melody 不是 unique 创作结果。

这是反版权哲学：旋律不应该被 monopoly。

## allthemusic.info 是什么

allthemusic.info 让用户输入一段旋律（几个 MIDI note），返回所有可能的相似旋律（similarity 阈值以上）。

如果一段旋律有 1000+ 相似版本，那这段旋律就不是 unique 创作。

法律意义：1000+ 相似旋律意味着这个 melody 不是 unique → 不应该被版权 → 是公开领域。

## 一人工程的反版权

solo engineer 选反版权哲学：

- AI 生成的所有旋律 = 公开领域
- solo engineer 不应该 monopoly 自己的创作
- solo engineer 应该让其他人 free use

反版权哲学的理由：

- 创作不是 unique → 不该 monopoly
- AI 生成的所有可能旋律 = 公开知识 = 全人类共同财产
- solo engineer 写完项目 = 公开代码 + 公开 README + 公开反版权声明

## solo engineer 的反 monopoly

solo engineer 不垄断：

- 代码：MIT / Apache / BSD 公开 license
- README：公开让所有人读
- 训练数据：公开来源（Pachet 2003 + simedw 2026 都是公开数据）
- 模型权重：公开下载（simedw 125M 模型在 GitHub）
- App Store：App Store 公开买，不是私下订阅

5 个公开 = solo engineer 的反 monopoly。

大公司项目：私有代码 + 私有 README + 私有数据 + 私有权重 + 私有 license = 反公开。

## 一人工程的反版权 cycle

solo engineer 的反版权 cycle：

- 项目 1：solo engineer A 写完，公开 README + 公开代码
- 项目 2：solo engineer B 读 README 继承项目 1，公开新 README
- 项目 3：solo engineer C 继承项目 2 + 反版权声明，公开新 README

3 代 solo engineer = 反版权 cycle。

allthemusic.info 是 solo engineer 反版权哲学的样板：生成所有可能旋律 = 公开领域。
