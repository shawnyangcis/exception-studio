大公司 vs 自由职业 vs 一人工程 详细：

3 类工程师 = 大公司 + 自由职业 + 一人工程。

## 类别 1：大公司

大公司：

- 100+ 人
- 1000+ GPU
- 多项目
- 季度 OKR
- 私密失败
- 利润起点
- 任期 2-5 年
- 频繁换工作

8 个大公司元素。

## 类别 2：自由职业

自由职业：

- 1 人
- 1 客户
- 1 项目（短期）
- 自由职业费率
- 公开完成
- 利润起点
- 任期 1-3 个月 / 项目
- 频繁换项目

8 个自由职业元素。

## 类别 3：一人工程

一人工程：

- 1 人
- 1 类工程师
- 1 项目（长期 = solo opus）
- 自给自足
- 公开失败
- love 起点
- 任期多年（代代相传）
- 不换项目（1 项目 = 1 类工程师）

8 个一人工程元素。

## 三方对照表

| 维度 | 大公司 | 自由职业 | 一人工程 |
|------|--------|----------|----------|
| 人数 | 100+ | 1 人 | 1 人 |
| 资源 | 1000+ GPU | 1 台机器 | 1 台机器 |
| 项目 | 多项目 | 1 项目（短期） | 1 项目（长期） |
| 视角 | 季度 OKR | 自由职业费率 | 代代相传 |
| 失败 | 私密失败 | 公开完成 | 公开失败 |
| 起点 | 利润起点 | 利润起点 | love 起点 |
| 任期 | 2-5 年 | 1-3 个月 / 项目 | 多年 |
| 换 | 频繁换工作 | 频繁换项目 | 不换项目（1 类工程师） |

8 个维度对照 = 三方哲学对照。

## 三方哲学

3 类哲学：

- 大公司哲学 = 团队 + 资源 + OKR + 季度
- 自由职业哲学 = 客户 + 项目 + 费率 + 短期
- 一人工程哲学 = 哲学 + 项目 + 长期 + 代代相传

3 类哲学对照。

## 三方的时间维度

3 个时间维度：

- 大公司时间 = 季度 OKR + 1-3 年
- 自由职业时间 = 1-3 个月 / 项目 + 几年累计
- 一人工程时间 = 多年 + 23 年 cycle + 200 年 cycle

3 个时间维度对照。

## 三方的失败哲学

3 个失败哲学：

- 大公司失败 = 私密失败清单 + 季度 review
- 自由职业失败 = 公开完成（不公开失败）
- 一人工程失败 = 公开失败清单 + README

3 个失败哲学对照。

## 三方的传播哲学

3 个传播哲学：

- 大公司传播 = 季度财报 + PR
- 自由职业传播 = LinkedIn + Upwork profile
- 一人工程传播 = HN show + GitHub + App Store + 80+ 篇散文

3 个传播哲学对照。

## 一人工程的独特性

一人工程的独特性：

- 不是大公司（不是 100+ 人 + 1000+ GPU）
- 不是自由职业（不是短期 + 频繁换项目）
- 是 1 人 + 1 哲学 + 1 项目（多年）+ 代代相传
- 自由职业哲学 + 大公司哲学 = 妥协版
- 一人工程哲学 = 不妥协版（哲学 + 长期 + 代代相传）

3 个一人工程独特性。

## 一人工程 vs 自由职业

一人工程 vs 自由职业：

- 一人工程 = 1 项目（多年）
- 自由职业 = 1 项目（短期）→ 频繁换项目
- 一人工程 = 哲学 + 长期
- 自由职业 = 利润 + 短期
- 一人工程 = 不换项目
- 自由职业 = 频繁换项目

6 个对照。

## 一人工程 vs 大公司

一人工程 vs 大公司：

- 一人工程 = 1 人
- 大公司 = 100+ 人
- 一人工程 = 1 项目
- 大公司 = 多项目
- 一人工程 = 公开失败
- 大公司 = 私密失败
- 一人工程 = 1 类工程师代代相传
- 大公司 = 100+ 工程师频繁换工作

8 个对照。

## 一人工程的哲学定位

一人工程的哲学定位：

- 一人工程 = 大公司哲学的反面（私密 → 公开）
- 一人工程 = 自由职业哲学的反面（短期 → 长期）
- 一人工程 = 一类工程师代代相传
- 一人工程 = 哲学 + 长期 + 公开 + 代代相传

4 个一人工程哲学定位。

## 一人工程的诗化总结

一人工程诗化总结：

- 大公司：100+ 人 + 1000+ GPU + 季度 OKR + 频繁换工作
- 自由职业：1 人 + 1 客户 + 1 项目短期 + 频繁换项目
- 一人工程：1 人 + 1 哲学 + 1 项目多年 + 代代相传

3 个诗化对照 = 一类工程师的多版本。
