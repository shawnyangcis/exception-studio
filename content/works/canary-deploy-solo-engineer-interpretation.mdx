canary deploy 一人工程解读详细：

金丝雀本意「下矿带金丝雀测毒气」→ solo engineer 自己就是 canary。

## 金丝雀本意

金丝雀本意：

- 矿工下矿带金丝雀（canary）
- 毒气泄漏时金丝雀最先中毒（鸟呼吸快，对毒气敏感）
- 金丝雀倒下 = 矿工撤离 = 救矿工一命
- 金丝雀 = 早期预警系统

3 个金丝雀角色。

## 软件 canary deploy

软件 canary deploy：

- 先发布给一小部分用户（金丝雀用户）
- 测版本是否正常
- 异常时只影响金丝雀用户
- 金丝雀用户 = 早期预警系统

3 个软件 canary 角色。

## solo engineer 自己就是 canary

solo engineer 自己就是 canary：

- solo engineer 先 release 给自己（不 release 给全部用户）
- 测版本是否正常
- 异常时 solo engineer 自己先倒下
- solo engineer = 早期预警系统

3 个 solo engineer canary 角色。

## 大公司 vs solo engineer canary 对照

大公司 canary：

- release 给 1% 用户（金丝雀用户）
- 测版本是否正常
- 异常时 1% 用户影响
- 大公司保护 99% 用户

solo engineer canary：

- release 给 solo engineer 自己
- 测版本是否正常
- 异常时 solo engineer 自己受影响
- solo engineer 保护全部用户（用户少）

2 个对照。

## 一人工程的金丝雀哲学

solo engineer 金丝雀哲学：

- 金丝雀本意测毒气（早期预警）
- 软件 canary deploy 是借用
- solo engineer 自己就是金丝雀（自己测）
- solo engineer 保护用户

4 个事实 = solo engineer 金丝雀哲学。

## 一人工程的金丝雀哲学总结

solo engineer 金丝雀哲学：

- 金丝雀本意 = 测毒气 + 早期预警
- 软件 canary = 借用金丝雀本意

- solo engineer 哲学核心 = 自我测毒

4 个事实 = solo engineer 金丝雀哲学的全部。
