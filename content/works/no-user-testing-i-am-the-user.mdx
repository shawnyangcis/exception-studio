团队有 user testing。

User testing：用户测试。Usability test：可用性测试。User research session：用户研究 session。Unmoderated test：无主持测试。Moderated test：有主持测试。UserTesting.com / Maze / Lookback：测试工具。$100-$500 / session。

每 SaaS 1 个 UX researcher + 1 个 user testing tool + 1 个 usability lab。$200K-$500K / 年。

solo engineer 没有 user testing。

我自己就是 user。

我想用什么就写什么、我想看什么就 commit 什么、我想怎么用就怎么用。我不需要 user testing、不需要 usability test、不需要 unmoderated、不需要 moderated、不需要 UserTesting.com。

我没 user testing 的必要——我是唯一用户。我没 usability test 的必要——我知道 usability。我没 user research session 的必要——我没 research session。我没 unmoderated test 的必要——没 moderator。我没 moderated test 的必要——没 moderator。我没 UserTesting.com 的必要——没 session。我没 Maze 的必要——没 prototype。我没 Lookback 的必要——没 session。我没 $100-$500 / session 的必要——没 session。我没 $200-$500K / 年 的必要——没 UX researcher。

团队的 user testing 价值是「找 usability 问题 + 验证 design + reduce friction」。前提是有 user、需要 usability 问题、需要 design validation。solo engineer 没这个问题——我是 1 个 user、我 = usability、commit log = design validation。

一人工程的 user testing = 我自己用。不是 $200K UX researcher。
