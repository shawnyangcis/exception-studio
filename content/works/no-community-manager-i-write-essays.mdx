团队有 community manager。

Community manager：管理 Discord / Slack / forum。Community engagement：每天回帖、组织活动。Ambassador program：找 10 个铁粉帮忙推广。Community guideline：发之前看规则。Monthly AMA：每月一次问任何问题。

每个社区 1 个 community manager + 1 个 mod。Discord server 5 个 = 10 个人。

solo engineer 没有 community manager。

我写散文就是 community。

我写 no-deploy-freeze，下一篇 no-canary-deploy，下下一篇 no-mockup。访问者点开看、自己留或走、自己 commit 自己 fork。我不需要 Discord server、不需要 mod、不需要 AMA。

我没 community manager 的必要——我没 Discord server。我没 community engagement 的必要——访问者自己看散文。我没 ambassador program 的必要——我不需要铁粉。我没 community guideline 的必要——散文标题就是 guideline。我没 AMA 的必要——没社区问我。

团队的 community manager 价值是「维护用户社区 + 提升 engagement」。前提是用户量大、需要 Discord 群、需要 ambassador。solo engineer 没这个问题——我的访问者自己来、不需要 engagement、commit log 是 community。

一人工程的 community = `git log`。不是 Discord server。
