one-man project vs solo opus 语义学详细：

一人工程的语言学 = 当代英语 + 拉丁文学双版本。

## one-man project 是什么

one-man project = 当代英语：

- one-man：一人（一人乐队 / 一人秀 / 一人项目）
- project：项目
- 当代用法：1 人做整个项目
- 例子：one-man band / one-man show / one-man startup

4 个 one-man project 元素。

one-man band 是什么意思：

- 一人乐队（一个人演奏多种乐器）
- 1960-1970 摇滚乐常用词
- 例子：Trent Reznor（Nine Inch Nails）

2 个 one-man band 例子。

one-man show 是什么意思：

- 一人秀（一个人表演）
- 戏剧 + 喜剧常用词
- 例子：很多喜剧演员

2 个 one-man show 例子。

## solo opus 是什么

solo opus = 拉丁语：

- solo：拉丁语 solus = 独自（男性）
- opus：拉丁语 = 作品（创作性作品）
- 拉丁文学用法：独自完成的作品
- 例子：Beethoven solo opus

4 个 solo opus 元素。

opus 是拉丁语「作品」：

- opus musicum = 音乐作品
- opus magnum = 伟大作品
- op.（作品编号缩写）

3 个 opus 用法。

## one-man project vs solo opus 对照

6 个对照：

- 语言：当代英语 vs 拉丁语
- 用法：1 人 + 项目 vs 1 人 + 作品
- 时间感：1 个项目（几月 ~ 几年）vs 持续作品（多年）
- 浪漫：普通人日常 vs 伟大作品
- 戏剧：日常 vs 严肃
- 翻译：直译 vs 文雅译

6 个对照。

## 一人工程的双版本

一人工程的双版本：

- 当代英语版：one-man project（普通人日常说法）
- 拉丁文学版：solo opus（文雅说法）
- 两个版本都是 1 人做 1 个作品

3 个一人工程双版本。

## 为什么选 solo opus

为什么一人工程选 solo opus（不只 one-man project）：

- solo opus = 文雅 + 古典 + 200 年传承
- solo opus = 持续多年的作品（不只是项目）
- solo opus = 文学语言（不是技术语言）
- solo opus = 与 Beethoven solo opus 衔接

4 个 solo opus 选择理由。

## 跟 Beethoven solo opus 的对照

Beethoven solo opus：

- Beethoven 作品编号 = Op. 27 No. 2（Für Elise 不算 Beethoven opus，常被称为 WoO 59）
- 严格说 Für Elise 是 WoO 59（Werke ohne Opuszahl）= 没有 opus 编号的作品

3 个 Beethoven opus 细节。

solo opus 一人工程的对照：

- 一人工程 solo opus = 1 人 + 持续多年 + 1 个作品
- Beethoven solo opus = 1 人 + 持续多年 + 多个作品
- 1 人 + 持续多年 = 共同特点

2 个 solo opus 对照。
