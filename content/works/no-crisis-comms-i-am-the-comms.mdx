团队有 crisis comms。

Crisis comms：危机公关。Press statement：媒体声明。Dark site：服务挂了展示的页面。Outage postmortem：事故报告。PR statement：Twitter / 博客公开。Spokesperson：公司发言人。Crisis PR agency：危机公关公司 $50K / 起。

每个事故 = 1 周危机公关 + $50K 律师 + $50K PR agency。

solo engineer 没有 crisis comms。

我自己就是 comms。

我写的散文挂了，我自己发推。我访问量掉了，我自己回 issue。我 git revert 一个 commit，我自己解释。没人需要 spokesperson、没人需要 PR statement、没人需要 dark site、没人需要 crisis PR agency。

我没 crisis comms 的必要——访问量 1000，没媒体关注。我没 press statement 的必要——没 TechCrunch 报道。我没 dark site 的必要——Vercel 自动 retry、git revert = 恢复。我没 outage postmortem 的必要——commit log 是 postmortem。我没 spokesperson 的必要——我 = spokesperson。我没 crisis PR agency 的必要——没 $50K。

团队的 crisis comms 价值是「保护 brand + 维护 stakeholder 关系」。前提是大公司、需要 brand protection、需要 stakeholder trust。solo engineer 没这个问题——我没 brand 要保护、没 stakeholder、commit log 是 trust。

一人工程的 crisis comms = `git revert` + commit message。不是 $50K crisis PR agency。
