solo engineer 不只是 founder。simedw 23 年路径里，先是 MIDI piano transformer 的算法工程师，再是 V7 contractor 的执行者，最后是 Tembo + piglix + Letters ZIP 的产品创始人。三件事同时压在一个人的肩上：做技术（maintainer）、做产品（founder）、讲技术（evangelist）。

AcceptMarkdown.com 的 Andy Kawasaki 一个月一个人守一条 markdown 兼容性的护城河，同样是三个角色叠加。一个人活成了一家公司。

HN show 8/27 评论者 isoprophlex 形容 simedw 的 Tembo：「man hits thing thing go plink」——洞穴人格式哲学。把复杂的 MIDI 表征转换成「撞一下 + 一个声音」的极简描述。solo engineer 不是把事情搞复杂，是把事情搞到不能再简单。一个人加一个 plink，就是一件完整的工作。

François Pachet 2003 年在 Sony CSL Paris 写 Continuator 时，也是一个人。23 年后 simedw 传承 = solo engineer 的接力棒。v2ex #765794 Yegor Bugaenko「I've been a solo founder for 18 years」帖：18 年 solo founder 跨度的孤独不是空间维度，是时间维度。

alyssarosenzweig.ca Asahi Linux GPU 工程师从硬件反向工程到 Linux 内核 patch，硬件 + 软件双重搏击的孤独是体力活；散文站是脑力活，但同样孤独。

散文站 = solo engineer = HN show evangelist。一个人既是 founder 又是 maintainer 又是 evangelist 又是读者又是评论者又是管理者。AcceptMarkdown 的 Andy Kawasaki 一个月一个人守一条兼容性；散文站一天一个人写一篇散文。孤独不是代价，是形态。simedw「算了，挺快乐」就是这种形态的签名。
