团队有 metaprogramming。

Metaprogramming：元编程。Macro：宏。Template metaprogramming：模板元编程。Code generation：代码生成。AST：abstract syntax tree。Reflection：反射。Introspection：内省。$0 / 月 in metaprogramming.

每 startup 1 个 metaprogramming + 1 个 macro library + 1 个 code generator。$100K-$300K / 年.

solo engineer 没有 metaprogramming。

我自己就是 metaprogramming。

我想 macro 就 macro、想 generate 就 generate、想 reflect 就 reflect、想 introspect 就 introspect。我不需要 metaprogramming、不需要 macro、不需要 template metaprogramming、不需要 code generation、不需要 AST、不需要 reflection、不需要 introspection.

我没 metaprogramming 的必要——我是 1 个 engineer 我写代码。我没 macro 的必要——没 macro。我没 template metaprogramming 的必要——没 template。我没 code generation 的必要——commit log 是 code generation。我没 AST 的必要——没 AST manipulation。我没 reflection 的必要——没 reflection。我没 introspection 的必要——没 introspection。我没 $100K-$300K / 年 的必要——没 metaprogramming team.

团队的 metaprogramming 价值是「让代码自动生成 + 减少 boilerplate + 抽象通用逻辑」。前提是有大量 boilerplate、需要抽象、需要 generation。solo engineer 没这个问题——访问量 1000、commit log 是 boilerplate、commit = 抽象.

一人工程的 metaprogramming = 我自己 + git commit。不是 macro library + code generator + metaprogramming team.
