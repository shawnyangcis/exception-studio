# simedw 的 41 个 repo：一人工程的活注脚

一个人能同时维护 41 个仓库吗？

Simon Edwardsson（simedw）的 GitHub 给出了答案：能，而且横跨 Python、Elixir、Haskell、PyTorch、WebAssembly、FUSE 六个完全不同的技术栈。

## 41 个 repo 的画像

simedw 的 GitHub profile 写着 "London | UK"，92 followers，PRO member。他的 41 个仓库不是"全栈工程师"的堆砌，而是一个人在不同方向上的探索：

- **mac-shhh**：一个 tiny、fully local 的 macOS menu-bar app。没有云端，没有账号，就是一个安静的小工具。
- **qkill**：对准一个窗口，杀掉它的进程。单一功能做到极致。
- **klonk**：一个 text editor，undo/redo 算法有点 unusual。技术选择有态度。
- **fetchfs**：FUSE filesystem，manifest-backed，read-only。技术深度。
- **spegel**：333 stars，用 LLM 重写网页的 terminal browser。AI + web。
- **pullsaw**：把大 PR 自动切成 stacked PRs。开发者 workflow。

这不是"全栈"，这是"全人"。

## 安静守护者哲学

mac-shhh 的描述是 "Shush at your Mac to lower its volume. A tiny, fully local macOS menu-bar app."

这句话可以原封不动地搬到散文站的写作哲学上：

- **tiny**：不刷存在感，写一篇就是一篇
- **fully local**：不依赖热点，不追逐流量
- **menu-bar app**：安静地在那里，你需要时打开就行

散文站也是 tiny、fully local 的。100+ 篇散文，每一篇都是一个独立的探索，不依赖平台的推荐算法，不追逐热搜。

## 技术栈极度多样

Python、Elixir、Haskell、PyTorch、WebAssembly、FUSE——这不是"全栈工程师"能覆盖的范围。这是一个人在不同方向上的好奇心。

散文站也是这样：从 Irving853 的绝望到 coolwulf 的 13 年浏览器，从 fzakaria 的 SQLite-as-EXE 到 Nolan Lawson 的前端教育。每一篇散文都是一个独立的技术方向，但都收敛到同一个哲学：一人工程。

## spegel 的启示

spegel 是 simedw 最流行的项目（333 stars）："A Terminal Browser That Uses LLMs to Rewrite Webpages."

这个项目的哲学是：网页不应该以原始 HTML 呈现，而应该通过 LLM 重写为更适合终端阅读的格式。

散文站做的事情类似：HN 和 V2EX 上的原始讨论不应该以原始帖子呈现，而应该通过"一人工程"的视角重写为更适合深度阅读的格式。

simedw 用 LLM 重写网页，散文站用"一人工程"重写 HN。

## 一人工程的活注脚

simedw 的 41 个 repo 不需要解释，不需要辩护。它们就是一人工程的活注脚：一个人可以在多个方向上探索，每个方向都可以做出有价值的东西。

散文站也是这样。100+ 篇散文不需要解释为什么这么多主题、这么多方向。它们就是一人工程的活注脚：一个人可以在多个方向上探索，每篇散文都可以是一个独立的、有价值的思考。

simedw 用代码写，散文站用文字写。
