团队有 cohort analysis。

Cohort analysis：队列分析。Retention curve：留存曲线。Cohort table：队列表。Retention rate：留存率。Churn rate：流失率。Mixpanel / Amplitude：cohort tool。DAU / WAU / MAU：日活 / 周活 / 月活。$200-$500 / 月 in cohort tool。

每 SaaS 1 个 data analyst + 1 个 growth team + 1 个 Mixpanel。$200K-$500K / 年。

solo engineer 没有 cohort analysis。

我自己就是 cohort。

访问者访问 = cohort 1。访问者回访 = retention。我 commit log = cohort。我不需要 Mixpanel、不需要 Amplitude、不需要 cohort table。

我没 cohort analysis 的必要——访问量 1000。我没 retention curve 的必要——commit log 是 retention。我没 cohort table 的必要——没 cohort 要 track。我没 retention rate 的必要——没 cohort 要 measure。我没 churn rate 的必要——访问者自己来或不来。我没 Mixpanel 的必要——Vercel analytics 够用。我没 Amplitude 的必要——我没 event 要 track。我没 DAU/WAU/MAU 的必要——访问量 1000。我没 $200-$500 / 月 的必要——Vercel free。

团队的 cohort analysis 价值是「理解 user retention + 优化 funnel」。前提是有 user、需要 retention analysis、需要 funnel optimization。solo engineer 没这个问题——访问量 1000、commit log = retention、commit = funnel。

一人工程的 cohort analysis = commit log + Vercel analytics。不是 Mixpanel $500/月。
