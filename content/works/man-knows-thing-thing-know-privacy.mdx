## privacy 是什么

privacy = solo engineer 对用户数据的保护承诺 = 端侧 / 0 上传 / 0 云端 / 0 月费 = 默认安全。

simedw 端侧跑模型，用户按键不传云端。这是 solo engineer 的隐私默认。

## privacy 是抽象层第十层

plink = 抽象层 1（领域）

privacy 跟其他九个不同：其他九个是工程 / 文档 / 动机层，privacy 是承诺层。

## privacy 是 solo engineer 的默认

大公司项目：privacy 是法务团队的工作（GDPR / CCPA / DPA / privacy policy）。

一人工程：privacy 是 simedw 写代码时的默认。

simedw 默认「端侧跑模型」，没有云端，privacy 默认是「不收集用户数据」。这不是设计选择，是代码约束——iPhone Core ML 模型在本地，用户按键只进入本地内存，不发到任何服务器。

## privacy 跟 cloud 的对照

solo engineer 选 pocket realtime，cloud realtime 必须上传音频：

- pocket realtime：0 数据上传 + 0 云端 + 0 隐私风险
- cloud realtime：必须上传音频 + 必须云端 + 必须隐私风险

simedw App Store privacy label：

- 数据不收集（no data collected）
- 数据不上传（no data uploaded）
- 数据不卖给第三方（no data sold to third parties）

这是 App Store privacy label 的最简版本——「nothing」。solo engineer 的 privacy label 默认是 nothing。

## privacy 是一人工程的差异化

大公司 AI 应用：

- OpenAI ChatGPT：必须上传对话（训练数据 + 服务日志）
- Google Gemini：必须上传 query（广告 + 服务日志）
- Midjourney：必须上传 prompt（训练数据 + 服务日志）

一人工程 AI 应用：

- simedw midi-autocomplete：不上传按键
- 其他 solo engineer iPhone app：大多数不上传

solo engineer 的隐私差异化是「端侧默认 = 0 数据 = 0 隐私风险」。
