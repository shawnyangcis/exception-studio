团队有 edge case。

Edge case：边界情况。Corner case：角落情况。Boundary case：边界情况。Edge case testing：边界测试。Exception handling：异常处理。Defensive programming：防御式编程。Boundary value：边界值。$0 / 月 in edge case testing.

每 startup 1 个 edge case + 1 个 exception handling + 1 个 QA engineer + 1 个 test team。$100K-$300K / 年.

solo engineer 没有 edge case。

我自己就是 edge case。

我想 edge 就 edge、想 corner 就 corner、想 boundary 就 boundary、想 handle 就 handle。我不需要 edge case、不需要 corner case、不需要 boundary case、不需要 edge case testing、不需要 exception handling、不需要 defensive programming、不需要 boundary value.

我没 edge case 的必要——commit log 是 edge case。我没 corner case 的必要——没 corner case。我没 boundary case 的必要——没 boundary case。我没 edge case testing 的必要——commit log 是 test。我没 exception handling 的必要——try/catch = exception handling。我没 defensive programming 的必要——我是 1 个 engineer 我写 code。我没 boundary value 的必要——没 boundary value。我没 $0 / 月 的必要——Vercel free + commit log。我没 QA engineer 的必要——没 QA engineer。我没 test team 的必要——没 test team。我没 $100K-$300K / 年 的必要——没 test infrastructure.

团队的 edge case 价值是「让 code 处理所有 boundary + 减少 bug + 提高 reliability」。前提是有 complex logic、需要测试、需要 reliability。solo engineer 没这个问题——访问量 1000、commit log 是 test、commit = reliability.

一人工程的 edge case = try/catch + git commit。不是 JUnit + boundary value + QA team.
