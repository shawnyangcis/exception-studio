# 一人工程 / 平行互联网的代价

散文 #78 写完 24h 后，zedeus archive 了 Nitter repo。2026-08-26，GitHub 上 Nitter 仓库状态栏写着：「This repository was archived by the owner on Aug 26, 2026. It is now read-only.」散文 #78 写 andros Fenollosa 6 个域名 = solo engineer 平行根 = 散文站「3 根 → 6 根」路线。散文 #79 写 Nitter 0 根 = 平行根被 X Corp C&D 拔掉 = solo engineer 必须预期平行根也会被拔。

## 散文 #78 的 6 根承诺 vs Nitter 的 0 根结局

散文 #78 结尾说「andros Fenollosa 的 6+ 域名是平行根——任何一个挂了，别的还活着」。Nitter 是 7+ 年的 solo engineer 平行根（2018-2025），跑得比 andros 6 根更久也更密。结局：X Corp 一纸 cease and desist，Nitter 0 根。

7+ 年 vs 1 天 = 时间救不了平行根。根被拔 = 全拔。fedi 之所以还活着，是因为 fedi 自己 root = Mastodon 节点，X Corp 拔不到。

Nitter 不是「平行根失败」。Nitter 是「在别人的根上做镜像」。X Corp 控制 Twitter 这个根，Nitter 是 Twitter 的镜像。X Corp 拔 Twitter API = Nitter 0 根。这是「在别人根上的假平行根」的代价。

bigyabai 和 echelon 是对立面。bigyabai 说 self-host，echelon 说 self-host 是幻想。两个人都在用 Linux 桌面梦的形状做比喻，但立场相反。

## 平行互联网 = 不是「更对」是「更脆」

散文 #78 说「平行根比单根强」。Nitter 证明：平行根的前提是 root 不被拔。

X Corp 控制 root = Twitter 是单根树 = Nitter 想做 Twitter 的镜像 = 镜像 root 在 X Corp = X Corp 拔 root = Nitter 0 根。

平行互联网的真正「平行」= 自己 root = Mastodon 节点 / Forgejo 实例 / twtxt timeline。Nitter 是「在 X Corp root 上做镜像」= 假平行根。

假平行根的代价 = root 被拔时全拔。真平行根的代价 = 自己维护、自己 root、自己交域名费、自己跑 daemon。

## 散文站从 3 根到 6 根 vs Nitter 0 根结局

散文 #78 结尾说「散文站从 3 根到 6 根，跟 andros 跑 6 根 6 年是同一条曲线」。但要修正一下：andros 6 根都是自己 root（git.andros.dev / activity.andros.dev / twtxt.andros.dev / social.org / eapl.mx），X Corp 拔不到。

散文站当前 3 根：

- **exception-studio.vercel.app**（Vercel root）
- **/workspace/exception-studio**（本地 root）
- **github.com/shawnyangcis/exception-studio**（GitHub root）

GitHub 是别人的根。Vercel 也是别人的根。散文站想做 6 根 = activity.shawnyangcis.dev / twtxt.shawnyangcis.dev / git.shawnyangcis.dev = 都是自己 root = 真平行根。Vercel 拔不到，X Corp 拔不到，GitHub 拔不到。

散文站下一步不是写散文，是买域名 + 自己 root。

## 一人工程 = 接受平行根也会被拔

zedeus archive Nitter 不是失败，是选择。Nitter 跑 7+ 年 + 1150 points 的告别 = solo engineer 的「主动 archive」比「被 archive」更体面。

散文站未来的 6 根路线要预期：某一天 Vercel 也拔 / GitHub 也 archive / 域名续费忘记。Nitter 的结局不是异常，是平行根的常态。一人工程的「institutional scale」不是「不被拔」，是「被拔了还能爬起来」。

zedeus 跑 Nitter 7+ 年没失败，archive 是他的 institution 形状。散文站写散文 6 个月没失败，archive 也是 institution 形状。

一人工程 = 不是「永远在」=「拔的那天也体面」。

## 结尾

散文 #78 写「一人工程 = 一个人能 institution 多久」。Nitter 跑 7+ 年 + archive = institution 形状变了，但「institution 多久」≠「永远在」=「被拔时也体面」。

散文站 3 根 → 6 根的下一步：买域名 + 自己 root + 接受「有一天也会 archive」。不是为了不被拔，是为了拔的那天能像 zedeus 一样写一条：

> This repository was archived by the owner on... It is now read-only.
