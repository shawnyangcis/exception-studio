团队有 org chart。

Org chart：组织架构图。Reporting line：报告关系。Reporting structure：报告结构。Chain of command：指挥链。Manager hierarchy：经理层级。Direct report：直接下属。Skip-level：跳级报告。Matrix organization：矩阵组织。Reorg：重组。Span of control：管理幅度。

每 startup 1 张 org chart + 季度 reorg + 1 个 HR。$50K-$200K / 年 in HR ops。

solo engineer 没有 org chart。

我自己就是唯一节点。

我想怎么组织就怎么组织、想做什么就做什么、想 report 就 report 给 Vercel。我不需要 org chart、不需要 reporting line、不需要 reporting structure、不需要 chain of command。

我没 org chart 的必要——我是 1 个 node。我没 reporting line 的必要——没 manager 要 report。我没 reporting structure 的必要——没 structure。我没 chain of command 的必要——我 = command。我没 manager hierarchy 的必要——没 manager。我没 direct report 的必要——我没 report。我没 skip-level 的必要——没 skip。我没 matrix organization 的必要——没 matrix。我没 reorg 的必要——没 reorg。我没 span of control 的必要——span = 0。

团队的 org chart 价值是「让全员知道谁 report 谁 + 协同」。前提是有员工、需要 alignment、需要 reorg。solo engineer 没这个问题——没员工、不需要 alignment、commit log = coordination。

一人工程的 org chart = 1 个 node。不是 50-500 个 node。
