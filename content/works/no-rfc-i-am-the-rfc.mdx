团队有 RFC。

RFC：Request For Comments。Design doc：技术设计文档。Technical specification：技术规范。Architecture decision record：ADR。Decision log：决策日志。Lightweight review：轻量级评审。$0 / 月 in document.

每 startup 1 个 RFC + 1 个 design doc + 1 个 ADR + 1 个 architect + 1 个 review board。$300K-$700K / 年.

solo engineer 没有 RFC。

我自己就是 RFC。

我想 request 就 request、想 comment 就 comment、想 decide 就 decide、想 record 就 record。我不需要 RFC、不需要 design doc、不需要 technical specification、不需要 ADR、不需要 decision log、不需要 lightweight review.

我没 RFC 的必要——我是 1 个 engineer 我写 commit message。我没 design doc 的必要——commit log 是 design doc。我没 ADR 的必要——commit log 是 ADR。我没 decision log 的必要——commit log 是 decision log。我没 lightweight review 的必要——commit log 是 review。我没 architect 的必要——没 architect。我没 review board 的必要——没 review board。我没 $300K-$700K / 年 的必要——没 RFC process.

团队的 RFC 价值是「让 design decision 透明 + 团队 review + 知识沉淀」。前提是有 team、需要 transparency、需要 review。solo engineer 没这个问题——我是 1 个 engineer、commit log 是透明、我 = review.

一人工程的 RFC = git commit message。不是 RFC + design doc 流程 + review board。
