团队有 career path。

Career path：职业路径。Career ladder：职业阶梯。IC track：individual contributor。Manager track：管理路线。Engineering ladder：E3-E7。Promotion：晋升。Leveling：定级。Career development：career 发展。Mentorship program：mentorship。Calibration：calibration。

每 startup 1 个 career ladder + 季度 calibration + 1 个 HR。$50K-$200K / 年 in HR ops。

solo engineer 没有 career path。

我自己就是 path。

我想怎么走就怎么走、我想做什么就做什么、我想 engineer 就 engineer、我想 designer 就 designer。我不需要 career ladder、不需要 IC track、不需要 manager track、不需要 promotion、不需要 leveling。

我没 career path 的必要——没 manager 要 assign。我没 career ladder 的必要——没 level 要 climb。我没 IC track 的必要——我是 IC。我没 manager track 的必要——我是 engineer。我没 engineering ladder 的必要——没 level。我没 promotion 的必要——没 title 要升。我没 leveling 的必要——没 level 要评。我没 career development 的必要——我 = development。我没 mentorship program 的必要——没 mentee。我没 calibration 的必要——没 rating。

团队的 career path 价值是「让员工知道下一步 + 留人」。前提是有员工、需要 visibility、需要 retention。solo engineer 没这个问题——没员工、不需要 visibility、commit log = progress。

一人工程的 career path = 我自己走的路。不是 E3-E7 ladder。
