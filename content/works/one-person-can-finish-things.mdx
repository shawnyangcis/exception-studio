# 一个人能搞定的事

simedw 的整个项目：

- 125M 钢琴 transformer
- iOS app RollTab
- 14 次实验
- 半年时间
- 一个 GitHub README
- MIT 协议

加起来是一个人能搞定的事的现代范例。

不是「一个人 + 团队」。

是「一个人 + 一台机器 + 一群工具 + 一个 GitHub + 一个 App Store」。

# 一个人能搞定的特征

- 总预算 < $10,000（4 × RTX 4090 二手 + iOS dev account + 电费）
- 总代码 < 50,000 行（PyTorch + Core ML + Swift）
- 总论文 < 50 篇（deliberately 没读太多）
- 总实验 = 14
- 总部署 = 1 个 iOS app

不是「一个人搞不定的事」：

- 100B 模型
- 几千万 GPU 小时
- 几百研究员
- 大模型时代的 LLM 训练

# 一人工程的清单

simedw 满足：

- 一个人
- 一个明确问题（钢琴 MIDI 续写）
- 一个标准架构（decoder-only transformer）
- 一个表征创新（NOTE 5 个 head）
- 一个训练目标（DPO + scheduled sampling）
- 一个部署目标（iPhone 15）
- 一个开源（GitHub + MIT）
- 一个发布（App Store）

缺一项都不行：

- 不是一个人 → 是 OpenAI
- 没有问题 → 是论文
- 没有创新 → 是复现
- 没有部署 → 是研究
- 没有开源 → 是闭源商业
- 没有发布 → 是 demo

# 一人工程的总和

simedw 不只做了一件「一人工程」的事。
他做了全部：

- 训练 = 一人工程（PyTorch + 64M + 14 次实验）
- 部署 = 一人工程（Core ML + INT8 + iOS）
- 评估 = 一人工程（自动 + 人耳 + Gemini pairwise）
- 发布 = 一人工程（GitHub + MIT + App Store）

每一件事都是「一个人 + 一个具体动作」。
没有 PR review。
没有会议日程。
没有 Slack 通知。

签名：solus opus。
