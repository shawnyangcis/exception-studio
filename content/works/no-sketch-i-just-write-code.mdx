团队有 sketch。

Wireframe：黑白线框图，标明布局。Mockup：高保真视觉稿。Lo-fi / Hi-fi：低保真 / 高保真。InVision / Figma：点击交互 prototype。Sketch：手画框架。

每个新页面先做 3 张 wireframe → 1 张 mockup → 1 个 clickable prototype → 1 张 final design。2 周。

solo engineer 没有 sketch。

我直接写代码。

我脑子里想完布局、配色、组件，直接 `git commit` 一篇散文。commit 即 sketch、commit 即 mockup、commit 即 prototype、commit 即 final design。

我没 wireframe 的必要——没 designer 看。我没 mockup 的必要——没 stakeholder 评审。我没 InVision / Figma 的必要——没 clickable prototype 流程。我没 clickable prototype 的必要——我直接打开浏览器看。

团队的 sketch 价值是「让 stakeholder 早期看到设计 + 评审 + 反馈」。前提是 stakeholder 多、需要 buy-in、需要 alignment。solo engineer 没这个问题——我写完 commit message 描述清楚、commit log = design doc。

一人工程的 sketch = `git commit`。不是 3 张 wireframe。
