solo engineer 哲学 17 核心（已写）+ 第 18 核心 = honesty。

solo engineer 选诚实不选假装。

## honesty 是什么

honesty = 诚实 = solo engineer 公开 5 件 + 公开失败 + 公开训练 + 公开评测 + 公开技术细节。

solo engineer 的诚实哲学跟大公司的假装哲学对照：

- solo engineer：公开 = 诚实
- 大公司：私密 = 假装

## 公开 5 件 + 不公开 4 件

solo engineer 公开 5 件：

1. README（7 层 spec + 失败清单）
2. 训练参数（DPO β=0.03 + 125M + 4 × RTX 4090）
3. 评测方法（Gemini pairwise + 自己听 + 一致率）
4. App Store（公开链接 + privacy label nothing）
5. 社区互动（HN show 评论 + GitHub issues 回复）

solo engineer 不公开 4 件：

1. 月收入（隐私）
2. 用户数据（隐私）
3. 内部实验笔记（隐私）
4. 失败的情绪（诚实但不必公开）

5 + 4 = 9 件 = solo engineer 对外姿态边界。

## 大公司假装 5 件

大公司假装 5 件：

1. PR = 公开失败（实际失败隐藏）
2. sprint review = 公开进度（实际进度滞后）
3. design review = 公开设计（实际设计已变更）
4. release notes = 公开新功能（实际新功能有 bug）
5. marketing = 公开产品价值（实际产品价值打折）

5 个假装 = 大公司的假装哲学。

## solo engineer 公开评测方法的诚实

simedw 评测方法公开：

- 自动指标：pitch n-gram + pitch entropy + chord density + 长停顿

3 个公开 = simedw 评测方法诚实。

## 假装 vs 诚实的 trade-off

假装 trade-off：

- 优点：私密 = 不被 copy
- 缺点：用户不能验证 = 不信任

诚实 trade-off：

- 优点：公开 = 用户能验证 = 信任
- 缺点：公开 = 能被 copy

2 个 trade-off。

solo engineer 选诚实（信任 > 不被 copy）。
大公司选假装（不被 copy > 信任）。
