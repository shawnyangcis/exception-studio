团队有 moat。

7 moats：brand / patents / network effect / scale / switching cost / cost advantage / trade secret。Warren Buffett：「必须有 moat 才能长期赚钱」。Patent：申请 $10K-$50K，审批 3 年。Trade secret：保密 5 年 + 员工保密协议。

每个 startup 设计 moat。1 年。

solo engineer 没有 moat。

我自己就是 moat。

访问者订阅我的 RSS、看我的散文、读我的 commit log。这是我的「moat」——没人能复制我、没人能伪造我的 commit history、没人能写我的散文。我写 no-deploy-freeze 写得比其他人深 = 我的 moat。

我没 brand 的必要——commit log 是 brand。我没 patent 的必要——我没技术要保护。我没 network effect 的必要——访问者 1000 不是 network。我没 scale 的必要——我就 1 人。我没 switching cost 的必要——访问者切换到我不要钱。我没 cost advantage 的必要——Vercel $20/月不算 cost advantage。我没 trade secret 的必要——散文公开。

团队的 moat 价值是「长期不被替代 + 持续赚钱」。前提是有 startup、有竞争对手、需要长期。solo engineer 没这个问题——我没竞争对手、我不赚钱、我不需要长期 moat——散文本身就是 moat。

一人工程的 moat = commit log。不是 7 个 moat 设计。
