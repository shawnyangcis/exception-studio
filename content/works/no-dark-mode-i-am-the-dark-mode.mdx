团队有 dark mode。

Dark mode：dark theme。Light mode：light theme。Theme switcher：theme toggle。System preference：prefers-color-scheme。Tailwind dark mode：class-based dark mode。Chakra color mode：React theme。$0 / 月 in CSS.

每 startup 1 个 dark mode + 1 个 light mode + 1 个 theme switcher。$50K-$200K / 年。

solo engineer 没有 dark mode。

我自己就是 dark mode。

我想 light 就 light、想 dark 就 dark、想 auto 就 auto、想 custom 就 custom。我不需要 dark mode、不需要 light mode、不需要 theme switcher、不需要 system preference。

我没 dark mode 的必要——我是 1 个 engineer 我写 CSS。我没 light mode 的必要——我 = light mode。我没 theme switcher 的必要——没 switcher。我没 system preference 的必要——没 preference。我没 Tailwind dark mode 的必要——没 Tailwind dark。我没 Chakra color mode 的必要——没 Chakra。我没 $50K-$200K / 年 的必要——没 theme engineer。我没 frontend engineer 的必要——我自己 frontend。

团队的 dark mode 价值是「让 user 选 theme + 减少 eye strain + 美观」。前提是有 user、需要 theme、需要 eye strain reduction。solo engineer 没这个问题——我是 1 个 engineer、commit log 是 theme、我 = eye strain。

一人工程的 dark mode = Tailwind dark: + commit log。不是 Chakra + 5 个 frontend engineer。
