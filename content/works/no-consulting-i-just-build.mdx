团队有 consulting。

McKinsey / Bain / BCG / Deloitte / PwC / EY / KPMG。每个 consulting firm = strategy consulting + management consulting + IT consulting + HR consulting。每个 consulting project = 50 页 deck + 100 张 chart + 5 个 consultant 6 个月。

每个 consulting project $1M-$10M。

solo engineer 没有 consulting。

我直接 build。

我想 build 什么就 build、build 完 commit 自己看。我不需要顾问、不需要 50 页 deck、不需要 100 张 chart、不需要 5 个人 6 个月。

我没 McKinsey 的必要——我没大公司决策要优化。我没 Bain 的必要——我没 strategy 流程。我没 Big Four 的必要——我没 audit / tax / advisory。我没 deck 的必要——commit message 描述清楚。我没 5 个 consultant 的必要——我一个人。

团队的 consulting 价值是「外部 expert 视角 + 复杂项目执行」。前提是项目复杂、需要 external perspective、需要 deck 汇报。solo engineer 没这个问题——我 = 一个人 build + commit，commit message 是我的 deck。

一人工程的 consulting = `git commit`。不是 50 页 deck。
