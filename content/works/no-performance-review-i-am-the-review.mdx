团队有 performance review。

Performance review：每年 1 次绩效。360 review：同事 + manager + 下属 + 客户都 review。KPI：key performance indicator。OKR：objectives + key results。Annual review：每年 1 次。PIP：performance improvement plan。Manager：review 员工。HR：calibration。Stack ranking：forced distribution。

每员工每年 1 次 review + 4-8 小时 + 1 个 manager。$1K-$5K / 员工。

solo engineer 没有 performance review。

我自己 review 自己。

我想 review 就 review、想看 KPI 就看 Vercel analytics、想看 OKR 就看 commit log、想看 PIP 就看我自己 stop。我不需要 manager、不需要 360、不需要 HR calibration、不需要 stack ranking。

我没 performance review 的必要——没 manager 要 review 我。我没 360 review 的必要——没人要 feedback。我没 KPI 的必要——我自己定。我没 OKR 的必要——commit log 是 OKR。我没 PIP 的必要——我 = 我自己劝自己。我没 stack ranking 的必要——没 ranking。

团队的 performance review 价值是「让员工知道表现 + 涨薪 + promotion」。前提是有员工、需要 align、需要 compensation。solo engineer 没这个问题——没员工、不需要 align、commit log = compensation。

一人工程的 performance review = 我自己看 commit log。不是 4-8 小时 + 1 个 manager。
