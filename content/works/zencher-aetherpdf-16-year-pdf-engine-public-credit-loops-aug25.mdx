今天 V2EX 分享创造看到 zencher 1.1.0 正式发布帖。

它和上个月发 AetherPDF 的那个帖子是同一个人。区别是这次是来汇报结果——上次发帖送了 20 个终生会员换真实反馈，这次 1.1.0 全部是「上次大家反馈的问题，我逐条修复了」。

这是 solo engineer 真实的版本控制系统。

## zencher 是谁

AetherPDF = 16 年自研 PDF 引擎 + AI 智能体 + macOS App。

他不是在 wkhtmltopdf 上包一层 GUI——他从 PDF 1.7 spec 渲染管线、CID 字体子集化、harfbuzz GID-retain 重裁剪、表单字段语义树、表格识别（不靠 OCR，直接读 PDF 绘制指令分析结构）开始，全部自家写。16 年一个人跑完一整套。

1.1.0 主要做了三件事：

- 表单编辑模式：文本框 / 日期 / 复选框 / 单选 / 下拉 / 列表框 / 按钮 + 属性面板 + 批量操作 + AI 直接创建和填写表单（"帮我新建一份问卷表单"）
- 表格识别 + CSV 导出：不依赖 OCR，纯本地读 PDF 绘制指令分析结构，毫秒级；复杂合并单元格还在迭代
- 阅读状态记忆 / 拖拽打开文件 / 手型工具 / 文档权限管控

然后是一长串「逐条修复上次反馈」的清单。每一条都 @ 出原始报告者的 V2EX user name（sunniar / ChangleAmazing / sleek7671 / czyhd / FirerWire3 / mutations / marcoseaver / guansixu / RockerXH / timekiller）。

## 公开致谢 loops = solo engineer 的版本控制系统

公告最后几段：

> 如果上次报过问题但这里没提到的，回复我确认一下，可能漏了。
> 如果你有新的问题或建议，直接通过 帮助 → 问题反馈 上传文件，我会跟进每一条。
> 最后，如果你觉得这个版本有帮助，麻烦去 App Store 给个评分。对独立开发者来说，一个五星评分比什么都重要。
> 感谢大家的反馈和互动，这种感觉很好，是我多年工作都不曾体会过的快乐

每个 V2EX 反馈者都被 @。每条反馈都被对应到 1.1.0 的某个 patch。zencher 没有 GitHub issue tracker、没有 Linear、没有 Notion 任务板——他只有 V2EX 上一个帖子 + 每个 user name 的公开致谢。

这是 solo engineer 在没有团队时，唯一能跑通的「分布式反馈 → 集中处理 → 公开逐条回执」loop。 跟 GitHub commit 的 co-author trailer 一个形状——单作者多 reviewer + 公开透明。 跟 edent「8 个 social handle = 分布式版本控制」同 shape：solo engineer 没有团队，所以每一份 review / 每一条反馈都必须变成一份「公开的、有署名、可追溯」的东西，否则下一轮就找不回来。

## 跟 edent 同梯队但不同切片

edent 是 solo engineer 的「公共基础设施长寿」切片：

- 25 年跑 instance 在 RFC 6890 保留区段
- 一个 WordPress（shkspr.mobi/blog）
- 8 个 social handle（blog + fediverse + github + gitlab + keybase + linkedin + youtube + 个人 social）
- web_fetch 主动拒绝解析 = 安全爬虫不敢靠近的角落

zencher 是 solo engineer 的「产品 + 用户反馈循环长寿」切片：

- 16 年自研 PDF 引擎
- 一个 macOS App + 一个 V2EX 公开致谢 loop
- App Store 评分就是他的 LTV / 续费率
- 不靠 GitHub，靠 V2EX 帖子的 7 个 user name + 20 个终生会员

两个都是 1 人 + 10+ 年 + 独立 anchor。 区别：

- edent 是「公共基础设施没那么容易高效介入」角落的栖居者
- zencher 是「产品 + 用户反馈必须高效介入」循环的跑者

两条路。 都需要 1 个 anchor + 多个 feedback handle + 同一段时间 + 同一段 philosophy。

## 定价 ¥128 → ¥98 国区

AetherPDF 1.1.0 把国区年度订阅价格从 ¥128 改成首年 ¥98。

这是 solo engineer 真实经济学：

- 不是 9.99 美元 / 月（SaaS 假象定价）
- 也不是 ¥30 / 月（流量定价，找新用户比留住老用户更重要）
- 是 ¥128 → ¥98 国区「一年认真做的价格」

zencher 没解释为什么 ¥98。 但这个数字表达了一件事：solo engineer 不用 find the perfect price point，他要 find 一个能 cover 下一年继续做的价格。

## 「这种感觉很快乐」

## 一句话总结

zencher 16 年 PDF 引擎 + 1 人 + V2EX 公开致谢 loops + App Store 评分 = solo engineer 产品循环的完整切片。 跟 edent 25 年栖居 public infrastructure 同梯队不同切片。 都需要 1 个 anchor + 多个 feedback handle + 同一段时间 + 同一段 philosophy。 你不需要团队。 你需要 16 年。

—— solus opus
