simedw 在 HN show 里说他是 V7 contractor，不是 V7 employee。

contractor 模式是 V7 给 ML research 工作的预算方式：V7 有 dataset annotation 需求、需要 SOTA piano continuation 模型、需要 iOS deployment 能力。V7 找 simedw 签 contract、按 milestone 付费、不需要 simedw 长期 commitment。

salary 比较：
- V7 employee ML engineer：$200K-400K USD/年 + equity + benefits（医疗保险、401k、PTO、visa sponsorship、relocation）
- simedw 的 V7 contract fee：$50K-100K USD/项目（按 milestone），没有 equity、没有 benefits、没有 stable income

simedw 选 contractor 模式。为什么？

> contractor 模式让 simedw 自由 ship 自己想 ship 的项目，不绑定到 V7 的 roadmap。

contractor 的核心 trade-off：stable income + benefits vs 自由 + 多项目。simedw 选自由——他不只做 V7，他还做：
- RollTab App Store（一半时间在 ship iOS app）
- HN show + community engagement（marketing 自己）
- open source sponsorship（GitHub Sponsors + Patreon 一部分人订阅）
- 给其他公司做短期 contract（ML consulting、music generation 短期项目）

contractor 模式让 simedw 的时间表 = 自己的，不是 V7 的。

> 一人工程的薪资模式不是 employee salary，是 contract fee + app revenue + sponsorship。

团队 engineer 的薪资模式：base salary + bonus + equity = 公司决定 ship 什么、自己做什么。manager 决定 sprint priority、PM 决定 roadmap、SVP 决定公司 strategy。engineer 只在 assigned task 上 ship。

一人工程 simedw 的薪资模式：contract fee（一次性项目付费）+ App Store revenue（订阅或一次性买）+ GitHub Sponsors（recurring monthly sponsorship）。每个收入源对应不同的工作：contract 给 V7 做 research、App Store 给自己做产品、sponsors 给 open source 做 free tier 用户。

vladislav-kalinkin 的 Ullis 也是同样模式——vladislav 不是大公司的 employee，是独立 open source maintainer。收入来源：GitHub Sponsors + consulting fee（给其他公司做 ternary MoE-Kan 集成）。一人工程的薪资模式是 mixed portfolio。

andalabx 的 Clean skill 也是同样模式——andalabx 不是大公司 employee，是 GitHub sponsor-driven indie developer。

> 团队的薪资模式是 base salary + equity。一人工程的薪资模式是 contract fee + product revenue + sponsorship。

trade-off：团队 employee 模式 stable income（每月工资准时到账）+ benefits（医疗保险 401k PTO）+ career ladder（senior → staff → principal → distinguished）。一人工程 contractor 模式 unstable income（contract 月份无收入）+ no benefits（自己买医疗保险、IRA 自己交）+ no career ladder（自己 ship + 自己 brand）。

但 simedw 接受这个 trade-off——contractor 模式让他 ship 自己的节奏，不被 V7 的 manager 决定 sprint priority。

solus opus.
