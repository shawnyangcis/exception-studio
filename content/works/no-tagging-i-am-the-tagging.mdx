团队有 tagging。

Tagging：打标签。Tag system：标签系统。Tagging taxonomy：标签分类法。Categorization：分类。Labeling：标记。Tag management：标签管理。OpenTag：open source tagging。Auto-tagging：自动打标签。$0-$500 / 月 in tagging tool.

每 startup 1 个 tagging + 1 个 tag taxonomy + 1 个 auto-tagging + 1 个 content team.。$50K-$200K / 年.

solo engineer 没有 tagging。

我自己就是 tagging。

我想 tag 就 tag、想 categorize 就 categorize、想 label 就 label、想 auto-tag 就 auto-tag。我不需要 tagging、不需要 tag system、不需要 tagging taxonomy、不需要 categorization、不需要 labeling、不需要 tag management、不需要 OpenTag、不需要 auto-tagging.

我没 tagging 的必要——访问量 1000 不需要 tag。我没 tag system 的必要——commit log = tag system。我没 tagging taxonomy 的必要——commit log 是 taxonomy。我没 categorization 的必要——commit log = categorization。我没 labeling 的必要——commit log = labeling。我没 tag management 的必要——commit log = management。我没 OpenTag 的必要——没 OpenTag。我没 auto-tagging 的必要——commit log = auto-tagging。我没 $0-$500 / 月 的必要——Vercel free。我没 content team 的必要——没 content team。我没 $50K-$200K / 年 的必要——没 tagging infrastructure.

团队的 tagging 价值是「让 content 可发现 + 可分类 + 可推荐」。前提是有大量 content、需要 search、需要 recommendation。solo engineer 没这个问题——访问量 1000、commit log 是 tag、我我 = categorization.

一人工程的 tagging = git tag + commit log。不是 OpenTag + auto-tagging + content team. .
