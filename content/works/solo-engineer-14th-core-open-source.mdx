solo engineer 哲学 13 核心（已写）+ 第 14 核心 = open source。

solo engineer 选开源不选闭源。

## open source 是什么

open source = 代码公开 + 训练数据公开 + 模型权重公开 + README 公开 + 失败清单公开。

5 个公开 = 一人工程的 openness。

## 跟闭源的对照

solo engineer vs 大公司闭源：

- solo engineer：5 个公开 = open source
- 大公司：5 个私有 = close source

大公司选闭源的原因：

- 代码私有 = 商业秘密
- 数据私有 = 数据是资产
- 权重私有 = 投入大量 compute 训练
- README 私有 = 内部文档
- 失败清单私有 = 不公开失败

5 个私有 = 大公司的 close source。

solo engineer 选开源的原因：

- 代码公开 = 公开学习
- 数据公开 = 公开知识
- 权重公开 = 公开模型
- README 公开 = 公开文档
- 失败清单公开 = 公开诚实

5 个公开 = solo engineer 的 open source。

## 一人工程的 open source 哲学

solo engineer 选 open source 因为：

- 1 人项目 = 没有商业秘密
- 1 人项目 = 没有数据资产
- 1 人项目 = 没有投入 compute 的独占性
- 1 人项目 = 没有内部文档
- 1 人项目 = 没有失败情绪

5 个没有 = solo engineer 选 open source 没有 trade-off。

## 一人工程的 open source 边界

solo engineer open source 的边界：

- 公开代码 = MIT / BSD / Apache 公开 license
- 公开数据 = 标注来源 + 公开数据集
- 公开权重 = Hugging Face + GitHub release
- 公开 README = 7 层 spec + 失败清单
- 公开失败清单 = 8 个失败 commit

5 个公开 = solo engineer open source 的边界。

solo engineer 不公开 4 件：

- 月收入（隐私）
- 用户数据（隐私）
- 内部实验笔记（隐私）
- 失败的情绪（诚实但不必公开）

5 公开 + 4 不公开 = solo engineer 对外姿态边界。

## 一人工程的 open source 收益

solo engineer open source 的收益：

- 学习：公开 README = 别人能学
- 合作：公开代码 = 别人能 contribute
- 信任：公开失败 = 别人信任
- 招聘：公开 commit log = 招聘优势
- 营销：公开项目 = HN show top 1

5 个收益 = solo engineer open source 的回报。

## 一人工程的 open source 代价

solo engineer open source 的代价：

- 时间：写 README + 失败清单 = solo engineer 时间投入
- 风险：公开 = 别人能 copy
- 收入：开源 = 不直接收 license 费
- 维护：开源 = 别人 issue 需要 solo engineer 回复

4 个代价 = solo engineer open source 的成本。

5 个收益 vs 4 个代价 = solo engineer 选 open source 因为收益 > 代价。

## 一人工程的 open source vs Apple App Store

simedw 的 open source 跟 App Store 上线有微妙的关系：

- 代码 + 权重 + 训练数据 + README = open source
- iOS app = App Store 闭源（闭源代码 = Apple NDA）

5 公开 + 1 闭源 = simedw 的混合策略。

solo engineer 可以混合 open + close：

- 项目本体（代码 + 权重）= open source
- 平台层（iOS app）= close source（Apple NDA 强制）

Apple NDA = solo engineer 不能 100% open source。

但其他部分（训练 + 评测 + README）= open source。

混合策略 = solo engineer 的现实选择。

## 一人工程的 14 核心哲学

solo engineer 哲学 14 核心：

1. 表征 > 优化
2. 推理 > 暴力
3. 选择 > 单次
4. actual understanding > simulated warmth
5. 公开 + 不公开边界
6. 表征是表征，模型是模型
7. 一人 pipeline = commit log
8. 一人 README = 7 层 spec
9. 端侧默认 = 0 隐私风险
10. 退出的勇气
11. 公开失败清单
12. love 是 solo engineer 起点
13. solo engineer 生态 = 23 年 + 200 年 cycle
14. open source 是 solo engineer 默认

14 个核心 = 24 + 4 篇散文 = 一人工程图景的全部。

## 一人工程的 open source 总结

solo engineer 选 open source 因为：

- 1 人项目 = 没有商业秘密
- 公开 5 件 + 不公开 4 件 = 对外姿态边界
- 5 收益 > 4 代价 = open source trade-off
- 混合策略（项目 open + 平台 close）= solo engineer 现实

4 个事实 = solo engineer open source 哲学的全部。
