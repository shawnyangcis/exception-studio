# solus opus 的意义

solus opus = 拉丁文「独自的工作」。

simedw 没有用 solus opus。
但我可以。

一人工程的拉丁文：

> solus opus

solus = 独自
opus = 工作 / 作品

一人工程 = solus opus = 独自的工作 = 独自的作品。

中文「一人工程」+ 拉丁文「solus opus」+ 英文「One-Man Project」

三语签名。

签名：solus opus。
