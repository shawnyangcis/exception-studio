团队有 backlog grooming。

Backlog grooming：backlog 整理。Backlog refinement：backlog refinement。Sprint planning：sprint 计划。Poker planning：planning poker。Estimation：估算。Story point：故事点。Velocity：velocity。$50-$200 / 月 in planning tool。

每 startup 1 个 backlog + 1 个 PM + 1 个 sprint planning。$100K-$300K / 年。

solo engineer 没有 backlog grooming。

我自己就是 backlog。

我想做什么就 commit = backlog。commit message = task description。commit log = sprint planning。我不需要 backlog grooming、不需要 sprint planning、不需要 poker planning。

我没 backlog grooming 的必要——我没 backlog 要 groom。我没 backlog refinement 的必要——commit log 是 refined。我没 sprint planning 的必要——commit log 是 planning。我没 poker planning 的必要——我自己 estimate。我没 estimation 的必要——我 = estimator。我没 story point 的必要——没 story。我没 velocity 的必要——commit 数 = velocity。我没 $50-$200 / 月 的必要——Vercel free。

团队的 backlog grooming 价值是「让 team align 优先级 + estimate effort」。前提是有 team、需要 align、需要 estimate。solo engineer 没这个问题——没 team、不需要 align、commit log = estimate。

一人工程的 backlog = git log + 散文。不是 Jira sprint planning。
