团队有 CISO。

CISO：chief information security officer。Security officer：安全官。SOC：security operations center。Security operations：安全运营。Threat intelligence：威胁情报。Vulnerability management：漏洞管理。Incident response：事故响应。$300K-$500K / 年。

每个 enterprise 1 个 CISO + 1 个 SOC + 5-10 个 security analyst。$2M-$10M / 年。

solo engineer 没有 CISO。

我自己就是 security。

我想怎么写就怎么写、想 commit 什么就 commit 什么、想 security 就 security。我不需要 CISO、不需要 security officer、不需要 SOC、不需要 threat intelligence。

我没 CISO 的必要——没 enterprise customer 要 SOC2。我没 security officer 的必要——没 enterprise compliance。我没 SOC 的必要——没 incident 要 triage。我没 security operations 的必要——没 24/7 ops。我没 threat intelligence 的必要——我没 threat surface。我没 vulnerability management 的必要——没 vulnerability。我没 incident response 的必要——我 = response。我没 $300K-$500K / 年 的必要——没 CISO。我没 $2M-$10M / 年 的必要——没 SOC。

团队的 CISO 价值是「保护 enterprise data + 合规 SOC2 + 应对 attack」。前提是有 enterprise data、需要 SOC2、需要应对 APT。solo engineer 没这个问题——没 enterprise data、不需要 SOC2、访问量 1000 没人 attack。

一人工程的 CISO = 我自己。不是 $2M SOC。
