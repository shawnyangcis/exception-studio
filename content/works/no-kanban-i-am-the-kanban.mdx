团队有 Kanban。

Kanban：看板。Kanban board：看板板。WIP limit：work in progress 上限。Pull system：pull 系统。Flow：流动。Cumulative flow diagram (CFD)：累积流图。Throughput：吞吐量。Cycle time：cycle time。Lead time：lead time。$50-$100 / 月每人。

每个 startup 1 个 Kanban board + 1 个 PM。$100K-$300K / 年。

solo engineer 没有 Kanban。

我自己就是 Kanban。

我想 commit 就 commit、想 push 就 push、想 deploy 就 deploy。我不需要 Kanban board、不需要 WIP limit、不需要 pull system、不需要 CFD。

我没 Kanban 的必要——没 board 要看。我没 Kanban board 的必要——没 team 要 align。我没 WIP limit 的必要——我是 1 个 WIP。我没 pull system 的必要——没 task 要 pull。我没 flow 的必要——我是 flow。我没 CFD 的必要——没 diagram 要画。我没 throughput 的必要——commit 数 = throughput。我没 cycle time 的必要——commit 间间隔 = cycle。我没 lead time 的必要——commit 到 deploy = lead time。我没 $50-$100 / 月 的必要——Vercel free。

团队的 Kanban 价值是「可视化 + 限制 WIP + 改善 flow」。前提是有 team、需要可视化、需要改善 flow。solo engineer 没这个问题——我是 1 个 WIP、commit log = 可视化、我 = flow。

一人工程的 Kanban = git log。不是 Kanban board $100/月。
