# Prompt 长度不是越长越好

> simedw 的 rollout 评估曲线：
>
> - 4-note prompt：最难
> - 8-note prompt：还行
> - 16-note prompt：显著靠谱
> - 32-note prompt：最稳

直觉反直觉：

- prompt 长 = 给模型更多信息 = 应该更好？
- 实际：4-note prompt 比 32-note prompt 更难

为什么？

- 4-note 给的上下文太少
- 模型要从很短的 seed 推断「风格 / 和声 / 节奏 / 调性」
- 这个推断难度比「接着已有风格延续」高得多

- 16-32 note 是「听感风格已建立」的甜蜜区
- 模型只需要「接着已有风格」

这跟 LLM 评估曲线类似：

- 短 prompt = 难度高
- 中长 prompt = 模型发挥稳定
- 超长 prompt = 模型开始重复 prompt

DPO 在短 prompt 上优势最小：

- 4-note 上 base vs DPO 差距小
- 16-32 note 上 DPO 拉开差距

原因：

- DPO 学的是「续写偏好」
- 续写需要「已建立风格」作为前提
- 没有风格，DPO 学的是噪声

- 评估大多在长 prompt 上
- 短 prompt 评估信噪比差
