# Copilot 在云上，simedw 在 iPhone 上

> simedw 在博客里说：
> 「Copilot for piano, like GitHub Copilot but for piano.」
> 「GPT-2 but for piano.」

GitHub Copilot 是 SaaS。
simedw 是 iPhone app。

两个产品的根：

- GitHub Copilot：VS Code 插件 + 远程 API + OpenAI GPT
- simedw：iOS app + 本地 transformer + Core ML

GitHub Copilot 每次按键都问 OpenAI。
simedw 每次按键问本地 transformer。

# GitHub Copilot 的架构

GitHub Copilot 一次按键的过程：

- VS Code 收集光标前 N token
- POST 给 GitHub Copilot 后端
- 后端转发给 OpenAI API
- OpenAI 跑 GPT 推理
- 返回 suggestion
- VS Code 显示给用户

每按一次键（甚至每次停顿时）：

- 1 次 HTTPS 请求
- 1 次 GPT 推理
- 1 次网络往返
- ~200ms 延迟

这是「云上 AI」的标准架构。

# simedw 的架构

simedw RollTab 一次按键的过程：

- iPhone 收集 prompt 的 8 个音
- Core ML 跑 125M transformer 推理
- 返回下一个 note
- iPhone 触发 MIDI

每按一次键：

- 0 次 HTTPS 请求
- 0 次网络
- 0 次服务器
- ~9ms 延迟（iPhone 实测 108 notes/sec）

这是「本地 AI」的标准架构。

# 两种「一人 + AI」

GitHub Copilot 团队：

- GitHub：1 家公司 + 工程师团队
- OpenAI：1 家公司 + 工程师团队
- 联合开发
- 多人 + 云 + 商业 SaaS

simedw：

- simedw：1 个人
- Core ML + iPhone：1 套平台
- 125M 模型：1 个训练产物
- 1 人 + 本地 + 一次性买断

# 「Copilot for piano」的本质

simedw 说「Copilot for piano」不是说产品形态一样。

是说**交互范式**一样：

- 用户输入一部分
- AI 续写下一部分
- 用户决定接受 / 修改 / 重来

两个产品都是「autocomplete for X」。
- X = code → GitHub Copilot
- X = piano → simedw

但**架构不同**：

- GitHub Copilot：Cloud autocomplete
- simedw：Local autocomplete

# Local 路线的优势

simedw 走 Local 的优势：

- 隐私：弹的曲子不上传
- 离线：飞机上也能用
- 零成本：没有 API 费用
- 零延迟：本地推理 ~9ms
- 无限用：没有 rate limit

Cloud 路线做不到这些。

# Local 路线的代价

simedw 走 Local 的代价：

- 必须在 125M 模型大小内（不能 GPT-3 大小）
- 必须 INT8 量化（不能 fp16）
- 必须 Core ML 兼容（不是 PyTorch）
- 必须 iPhone 用户（不是 Android）

# 一人工程的本地选择

simedw 选 Local 不是「我反对 SaaS」。

是「Local 对一人工程更适合」：

- 没有公司服务器 → 不用交钱给 AWS
- 没有 API key → 不用处理 OAuth
- 没有 rate limit → 不用排队
- 没有用户隐私问题 → 不用 GDPR

一个人 + 1 个 iPhone app = 完全自留。

如果 simedw 做 Cloud 路线：

- 需要后端服务器
- 需要数据库存用户偏好
- 需要 CDN 分发
- 需要 API 网关
- 需要运维
- 需要法务

Local 路线砍掉所有这些。
1 个人能做。

# 一人工程的 Local 哲学

不只是 simedw：

- Ollama：Local LLM
- llama.cpp：Local inference
- Stable Diffusion WebUI：Local image gen
- Suno offline：Local music gen

一人工程的现代版本越来越多 Local。

# 一人工程的 Local + 一人

Local + 一人 = 最纯净的 solo project：

- 没有别人能控制
- 没有别人能收费
- 没有别人能修改
- 没有别人能拒绝

iPhone 上跑模型 = 一个人的 iPhone + 一个 transformer = 一个 solo product。

这是「一人工程」在 2026 年的版本：
不是「一人 + 公司 + 商业」
是「一人 + 设备 + 模型 + app」。

签名：solus opus。
