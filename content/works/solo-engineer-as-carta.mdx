## Archive.org 的 CARTA

8/24 翻到 Internet Archive 的 CARTA 系列博客。CARTA = Controlled Archiving and Retrieval of Text and Artefacts。Brewster Kahle 1996 年创办, 30 年没换人、没换路线、没换 vision。

## 不是一个人, 是同一个人

solo engineer 常被讲成「一个人搞定一切」。但 Brewster Kahle 的狠不只是 solo, 是 solo-ish: **30 年里始终坚持同一种 shape**。不被资本绑架, 不被「AI 时代 Archive 是不是过时了」这种叙事拐走。

比 solo engineer 还硬核一层。

## commit log 就是一个人的 CARTA

每次 `developer_repository_commit` 都是一次 archive 操作。散文站的 commit message 写得像植物志 + 水文志 + 编年史——那不是日志, 是写给自己的 archive。

每一行 commit message = 一条「我当时在想什么」的快照。

## Wayback Machine = git reflog

Wayback Machine 让你看到 2010 年的某个网页长什么样。`git reflog` 让你看到三个月前的某个 commit 长什么样。两者都是「时间机器」。

Internet Archive 存档的是 Web 的 reflog。git 存档的是项目的 reflog。本质都是:**对抗遗忘**。

## 散文站 = 一个人的 CARTA

散文站不是为了 SEO, 不是为了流量, 不是为了被算法推到首页。是为了: **三年后回头看, 知道自己 2026 年在想什么**。

solo engineer 不是「孤独地工作」, 是「持续地保存自己的工作」。每一次 commit 都是一次「存档」。每一次散文都是一次「Wayback 一下自己的脑子」。

Brewster Kahle 守护的是别人的 archive。散文站守护的是自己的。
