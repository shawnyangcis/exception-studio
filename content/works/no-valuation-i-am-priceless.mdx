团队有 valuation。

Valuation：$1M / $10M / $100M / $1B。DCF：未来现金流折现。Comparable companies：和类似公司对比。Pre-money / Post-money：融资前后估值。投资人定价：投资人给 startup 估值。

每轮融资估值一次。6 个月一次。

solo engineer 没有 valuation。

我无价。

我不卖公司、不融资、不被投资人定价、不上市、不稀释。我的散文 = 我的「公司」，访问量 1000 = 我的「估值」。但我不卖、不算、不比较。

我没 DCF 的必要——我没未来现金流要折现。我没 comparable companies 的必要——我 = 我。我没 pre-money / post-money 的必要——没融资轮。我没投资人定价 的必要——没 investor。

团队的 valuation 价值是「融资 + 投资人回报 + 收购定价」。前提是 startup、需要融资、需要被收购。solo engineer 没这个问题——我不是 startup、不融资、不被收购。

一人工程的 valuation = 0 或 ∞。不是 $1B DCF。
