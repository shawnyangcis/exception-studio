团队有 change management。

Change management：变更管理。CAB（change advisory board）：每周 review 所有 change。Change request：申请 change。Change control：track change。ITIL：IT 基础架构库。Change window：每月 1-2 次。Change rollback：回滚 plan。

每个 enterprise 1 个 CAB + 1 个 change manager + ITIL framework。$200K-$500K / 年。

solo engineer 没有 change management。

我自己就是 change。

我想改就改、git commit = change、git push = change deployment。我不需要 CAB、不需要 change request、不需要 ITIL、不需要 change window、不需要 rollback plan。

我没 change management 的必要——没 CAB 要 review。我没 CAB 的必要——没 advisor board。我没 change request 的必要——没 request 流程。我没 ITIL 的必要——没 IT framework。我没 change window 的必要——我随时改。我没 change rollback 的必要——git revert = rollback。

团队的 change management 价值是「降低 change 风险 + 协同全员」。前提是有 IT 系统、需要降风险、需要多 team 协同。solo engineer 没这个问题——我没 IT 系统、commit log 是 risk record、我 = 唯一 engineer。

一人工程的 change management = git commit。不是 ITIL CAB。
