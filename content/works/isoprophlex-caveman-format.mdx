HN simedw 帖子的评论区里，isoprophlex 写了一段洞穴人格式：

> "man hits thing thing go plink machine hear plink machine make many more plink man happy for plink is fun man not hit machine with club or scream on orange site man leave cave and touch plant"

77 条评论里这一条被点了多次赞。

simedw 用 4 × RTX 4090 跑 12 分钟 DPO 训练 + 半天预训练 + 700 DPO preference examples + 125M transformer + bar/measure token + compound note events + KV cache ring buffer。HN 里的技术讨论把这些工程细节堆成几十层栈。isoprophlex 把它们全扔掉，只留一句话：

`man hits thing thing go plink.`

这是 simedw 工作的最小语言单位——一个人按键、一个机器听音、一个机器仿造更多音、人因为好玩而开心。剩下的所有事——MIDI token、表征设计、loss 曲线、iOS app 发布、Hacker News 营销——都只是这个最小事件的工程展开。

> 一人工程把复杂系统压缩到一句话的能力，是 simedw 们的共同姿态。

vladislav-kalinkin 在 HN 里描述 Ullis 的时候没有讲 ternary MoE-Kan 的 gate 公式，他说「a tiny MoE that runs anywhere」。andalabx 描述 Clean 没有讲 agent skill 的 5.3 GB 具体怎么组织，他说「tell your dev junk where to go」。这些都不是营销口号，是洞穴人格式——把 engineering 的全部工作量压缩成一个普通人都能听懂的最短句。

simedw 自己写 RollTab README 的时候其实也是洞穴人格式：「A piano that helps you play.」不是「A 125M-parameter transformer-based MIDI piano completion engine deployed via Core ML on iOS devices with KV cache ring buffer and bar/measure tokenization」。

前者是洞穴人格式。后者是 HN 评论里 simedw 偶尔的技术细节，但 *第一句话* 必须是洞穴人格式——因为一人工程的 commit、app store 上架页、Hacker News 标题，都只允许有一句话。

那一句话必须是 man hits thing thing go plink。

> 不是简化。是抵达。

simedw 抵达的不是「简化版」——是他把整个 700 DPO examples + 4 × RTX 4090 + 半年的工程之后，重新站回洞穴人面前说：「man happy for plink is fun」。

一人工程的洞穴人格式，是从工程深处向语言表面的反向穿透。

solus opus.
