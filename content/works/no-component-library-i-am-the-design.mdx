团队有 component library。

Component library：组件库。Storybook：组件展示工具。Design tokens：颜色 / 字体 / 间距的 token。Figma library：Figma 组件库。Material UI / Chakra / shadcn：第三方 component library。$5K-$50K / 年 in design system。

每 startup 1 个 design system + 1 个 design ops + 1 个 Storybook。$200K-$500K / 年。

solo engineer 没有 component library。

我自己就是 design。

我想怎么写就怎么写、我想用什么样式就用什么样式、我想 commit 就 commit。我不需要 component library、不需要 Storybook、不需要 design tokens、不需要 Figma library。

我没 component library 的必要——我没 50 个 component 要 maintain。我没 Storybook 的必要——没 component 要展示。我没 design tokens 的必要——没 design system 要 enforce。我没 Figma library 的必要——我没 Figma。我没 Material UI 的必要——我自己写 CSS。我没 Chakra 的必要——我自己写 CSS。我没 shadcn 的必要——我 = shadcn。

团队的 component library 价值是「让 designer + engineer 复用 component」。前提是有 50+ component、有 designer + engineer、需要 consistency。solo engineer 没这个问题——没 50 component、我 = designer + engineer、commit log = consistency。

一人工程的 component library = 散文 + commit log。不是 Storybook $200K。
