# 两套 framing：Copilot 与 Duet

> simedw 自评：
> 「Copilot for piano, like GitHub Copilot but for piano.」
> 「GPT-2 but for piano.」
>
> Naitik88 HN 评论升级：
> 「感觉不只是 autocomplete，更像另一个音乐家在实时响应你。」

两套 framing：

- simedw 自己：Copilot（工具）
- Naitik88：Duet（伙伴）

两套 framing 描述的是同一个产品。
同一个产品可以装两套 framing。

# Copilot framing

Copilot framing：

- 用户输入
- 模型续写
- 用户决定接受 / 拒绝

技术层是 autoregressive continuation：

- 给 prompt
- 模型生成 next token
- 用户消费

Copilot framing 的优点：

- 一听就懂
- 跟 GitHub Copilot 类比
- 「autocomplete」一词清晰

Copilot framing 的代价：

- 听起来像工具
- 听起来像服务
- 听起来像 product

# Duet framing

Duet framing：

- 用户弹
- 模型接
- 两个人形成即兴对话

体验层是 duet：

- 用户在弹
- 模型在接
- 实时同步

Duet framing 的优点：

- 听起来像艺术
- 听起来像伙伴
- 听起来像协奏

Duet framing 的代价：

- 不像 GitHub Copilot 类比
- 不像 autocomplete 类比
- 解释成本更高

# 两个 framing 对照

| 维度 | Copilot framing | Duet framing |
| --- | --- | --- |
| 类比 | GitHub Copilot | 古典合奏 |
| 用户角色 | 决定者 | 协奏者 |
| 模型角色 | 工具 | 伙伴 |
| 体验层 | 自动完成 | 实时对话 |
| 解释成本 | 低 | 高 |
| 听起来像 | productivity tool | 艺术合作 |

# 为什么 simedw 选 Copilot framing

simedw 选 Copilot framing 是妥协：

- Copilot 是行业的标准类比
- Copilot 一听就懂
- Copilot 有现成用户群（开发者）

simedw 的妥协策略：

- 产品体验是 duet
- 文案是 Copilot
- 让最大多数人听得懂

# 为什么 Naitik88 选 Duet framing

Naitik88 选 Duet framing 是诚实：

- 「感觉不只是 autocomplete」
- 「更像另一个音乐家」
- 「实时响应」

Naitik88 的真实体验：

- 用了 simedw 的 app
- 不是 autocomplete 体验
- 是 duet 体验

Naitik88 升级 framing 是因为：

- 真实体验 ≠ 文案
- 真实体验 = duet
- 文案 = Copilot（simedw 妥协）

# 两套 framing 都属于 simedw

simedw 的 1 人 + 1 个 iPhone app：

- 文案层：Copilot（妥协 + 易懂）
- 体验层：Duet（真实 + 准确）

两个 framing 同时存在：

- Copilot 是 simedw 对外说的
- Duet 是用户实际体验的

两个 framing 都不假：

- Copilot 不是骗人（确实是 autoregressive）
- Duet 不是夸大（确实是实时响应）

两个 framing 都是真的。

# 一人工程的双 framing

一人工程经常有双 framing：

- 文案层 vs 体验层
- 对外说 vs 实际是
- 妥协 vs 诚实

OpenAI 没有这个双 framing：

- 文案层：AGI
- 体验层：聊天机器人
- 文案 ≠ 体验
- 但文案被选为唯一 framing

simedw 有两个 framing：

- Copilot（文案层）
- Duet（体验层）

两个都属 simedw。

# 一人工程的态度

simedw 不该只保留 Copilot framing：

- 失去真实体验

simedw 不该只保留 Duet framing：

- 失去易懂文案

两个都保留：

- Copilot 给不懂的人
- Duet 给用过的用户

这是「一人工程的双 framing 哲学」：

> 我自己说 Copilot（易懂）。
> 用户说 Duet（真实）。
> 两者都是我。

签名：solus opus。
