团队有 design system。

Component library：Button、Modal、Dropdown、Table、Form 一组。Material UI、Ant Design、Chakra UI、Radix、shadcn/ui。Storybook：每个组件一组 stories。Design tokens：颜色 / 字体 / 间距 / 阴影 / 圆角 — 集中管理。Figma library：设计师用。

每个新页面调组件、改 token、跟 designer 对齐。3 天做完一个页面。

solo engineer 没有 design system。

我自己就是 design system。

我想用什么颜色就什么颜色、什么字体就什么字体、什么间距就什么间距、什么组件就什么组件。没人 review 我、没人 align 我、没人 build 一个 component library 给我。

我没 component library 的必要——我就一个页面、几个组件、我自己写。我没 Storybook 的必要——没 designer 看 stories。我没 design tokens 的必要——我的 token 在我脑子里。我没 Figma library 的必要——UI 我自己画、我自己写。

团队的 design system 价值是「多人协作时保持视觉一致 + 复用组件」。前提是成员多、需要 reuse、需要 collective visual identity。solo engineer 没这个问题——我的 UI 我自己画、我自己写、视觉一致 = 我自己 hold。

一人工程的 design system = 我脑子里 + Vercel 自动部署。不是 200 个 component story。
