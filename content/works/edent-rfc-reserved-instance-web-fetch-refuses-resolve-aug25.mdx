## RFC 保留区段栖居 = solo engineer 的「安全爬虫拒绝解析」哲学

RFC 6890 划定 `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`、`233.252.0.0/24` 为文档示例保留段。`e164.arpa` 反向映射 E.164 电话号码到 IP——也在保留名单里。

正常 SaaS 工程师不会把产品跑在保留 IP 上，因为没有 DNS 权威、没有公网路由、没有 CDN。**但 solo engineer 会**——因为保留区段恰恰是「不被别人打扰」的角落。

`web_fetch` 对 e164.arpa 拒绝解析的返回，本身就是 edent 哲学的最强 anchor：

> **你的 instance 安全到连安全爬虫都不敢靠近**。
