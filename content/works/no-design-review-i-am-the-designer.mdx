团队有 design review。

UI review：PM + designer + engineer 一起看 Figma。UX review：交互流程评审。Design critique：每两周设计师互相给反馈。Figma review：每个新页面开一个 Figma 文件，多人评论。Style guide review：设计 token 改动评审。

每改一个页面评审 1 小时。1 周 5 小时评审。

solo engineer 没有 design review。

我自己 design。

我想用什么颜色就什么颜色、什么字体就什么字体、什么布局就什么布局、什么交互就什么交互。没人评审我、没人评论我、没人给我反馈。

我没 UI review 的必要——UI 我自己画、我自己 review。我没 UX review 的必要——交互我自己定义。我没 design critique 的必要——没设计师互相反馈。我没 Figma review 的必要——Figma 我一个人用。我没 style guide review 的必要——没 design token。

团队的 design review 价值是「多人协作时保持 UX 一致 + 早期发现可用性问题」。前提是设计师多、需要 consistency、需要 UX feedback。solo engineer 没这个问题——我 = designer + engineer + PM，UX 一致性我自己 hold，可行性我自己测。

一人工程的 design review = 我打开浏览器自己看。不是 1 小时评审会议。
