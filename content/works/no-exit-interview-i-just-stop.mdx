团队有 exit interview。

Exit interview：员工离职前 HR 面谈。Exit survey：离职问卷。Alumni network：离职后保持。离职原因：better opportunity / manager / culture / compensation。HR：分析离职数据。Off-boarding：交电脑、交账号、交 badge。

每离职 1 个员工 = $5K HR + 30 分钟面谈 + 5K alumni / 年。

solo engineer 没有 exit interview。

我直接 stop。

我不想做了 = 我 stop。我不需要 HR、不需要离职问卷、不需要 alumni network、不需要 off-boarding、不需要交电脑。

我没 exit interview 的必要——没 HR。我没 exit survey 的必要——没离职问卷。我没 alumni network 的必要——没 alumni。我没 离职原因 分析的必要——没 manager 要 blame。我没 off-boarding 的必要——没电脑要交。我没 exit notice 的必要——我不 notice 自己。

团队的 exit interview 价值是「理解离职原因 + 改善 retention」。前提是有员工、有离职、需要数据。solo engineer 没这个问题——没员工、没离职、commit log 是 retention。

一人工程的 exit interview = git archive + last commit。不是 $5K HR。
