团队有 OKR。

Objectives and Key Results：每个季度公司 OKR → team OKR → 个人 OKR。每条 Objective 配 3-5 个 Key Results。Quarterly review：每季度末评估完成度 0.0-1.0。Annual goal：每年定一次大方向。Stretch goal：故意设高、达到 0.7 就算成功。

每季度写 OKR + review。1 年 4 次。

solo engineer 没有 OKR。

我自己定目标。

我想做什么就什么目标、想 review 就 review、想改就改。没人 review 我的 OKR、没人逼我设 stretch goal、没人对齐我到公司目标。

我没 Objectives 的必要——没公司目标要对齐。我没 Key Results 的必要——没 stakeholder 看数字。我没 quarterly review 的必要——我自己决定完成度。我没 annual goal 的必要——我每年 1 月想 30 秒就够。我没 stretch goal 的必要——我不想 stretch。

团队的 OKR 价值是「多人公司需要目标对齐 + 可衡量进度」。前提是公司大、需要对齐、需要可衡量。solo engineer 没这个问题——我的目标 = 我自己、我不需要对齐、commit log 是可衡量。

一人工程的 OKR = commit message + 散文列表。不是 quarterly Google Sheet。
