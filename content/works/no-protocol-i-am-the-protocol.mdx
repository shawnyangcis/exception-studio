团队有 protocol。

Protocol：网络协议。Network protocol：网络协议。HTTP：超文本传输协议。WebSocket：全双工通信协议。gRPC：Google remote procedure call。GraphQL：Facebook query language。REST：representational state transfer。TCP：transmission control protocol。UDP：user datagram protocol。WebRTC：web real-time communication。$0-$100 / 月 in protocol implementation.

每 startup 1 个 gRPC + 1 个 GraphQL + 1 个 REST + 1 个 protocol engineer。$100K-$300K / 年.

solo engineer 没有 protocol。

我自己就是 protocol。

我想 request 就 request、想 response 就 response、想 stream 就 stream、想 query 就 query。我不需要 protocol、不需要 network protocol、不需要 HTTP、不需要 WebSocket、不需要 gRPC、不需要 GraphQL、不需要 REST、不需要 TCP、不需要 UDP、不需要 WebRTC.

我没 protocol 的必要——Vercel = HTTP。我没 network protocol 的必要——没 network。我没 HTTP 的必要——Next.js = HTTP。我没 WebSocket 的必要——没 WebSocket。我没 gRPC 的必要——没 gRPC。我没 GraphQL 的必要——没 GraphQL。我没 REST 的必要——Next.js = REST。我没 TCP 的必要——Vercel = TCP。我没 UDP 的必要——没 UDP。我没 WebRTC 的必要——没 WebRTC。我没 $0-$100 / 月 的必要——Vercel free。我没 protocol engineer 的必要——没 protocol engineer。我没 $100K-$300K / 年 的必要——没 protocol implementation.

团队的 protocol 价值是「让 service 之间通信标准化 + 跨语言 + 跨平台」。前提是有 distributed service、需要 standardization、需要 cross-platform。solo engineer 没这个问题——访问量 1000、Next.js = protocol、commit log 是 cross-platform.

一人工程的 protocol = Next.js API Routes + Vercel。不是 gRPC + GraphQL + REST + protocol engineer.
