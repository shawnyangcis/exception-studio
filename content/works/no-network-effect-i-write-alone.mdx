团队有 network effect。

Metcalfe's law：网络价值 = N² 用户。Network effect：用户带来用户。Cross-side network：买家 + 卖家。Flywheel：内容 → 用户 → 商家 → 内容。Winner-take-all：市场份额 80%。

每个 startup 都设计 network effect。1 个设计 = 1 年。

solo engineer 没有 network effect。

我写就是飞轮。

我写 no-deploy-freeze，下一篇 no-canary-deploy，下下一篇 no-mockup。访问者 RSS 订阅、commit log 是 timeline、散文是 content。下一个访问者看到 10 篇散文 = 飞轮。

我没 Metcalfe's law 的必要——访问量 1000 不是 N²。我没 cross-side network 的必要——我没买家卖家。我没 winner-take-all 的必要——访问者自己来。我没 1 年设计 network effect 的必要——commit log = network effect。

团队的 network effect 价值是「快速 scale + 锁定市场」。前提是用户量大、需要双边、需要 winner-take-all。solo engineer 没这个问题——我不需要 scale、我不需要双边、commit log = flywheel。

一人工程的 network effect = `git commit`。不是 1 年设计。
