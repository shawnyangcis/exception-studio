团队有 PagerDuty。

PagerDuty：on-call + alert + incident paging。Opsgenie：Atlassian 的 PagerDuty alternative。Incident.io：modern incident management。FireHydrant：incident response。VictorOps：Splunk On-Call。$21-$41 / user / 月。

每 SaaS 1 个 PagerDuty + 1 个 on-call rotation + 1 个 incident response。$300K-$700K / 年。

solo engineer 没有 PagerDuty。

我自己就是 PagerDuty。

我想 page 就 page、想 alert 就 alert、想 incident 就 incident、想 on-call 就 on-call。我不需要 PagerDuty、不需要 Opsgenie、不需要 incident.io、不需要 FireHydrant。

我没 PagerDuty 的必要——访问者不 page 我。我没 on-call 的必要——我自己 = on-call。我没 alert 的必要——没 alert 要 send。我没 incident paging 的必要——没 incident 要 page。我没 Opsgenie 的必要——没 Opsgenie。我没 incident.io 的必要——没 incident.io。我没 FireHydrant 的必要——没 FireHydrant。我没 VictorOps 的必要——没 VictorOps。我没 $21-$41 / user / 月 的必要——Vercel free。我没 $300K-$700K / 年 的必要——没 on-call rotation。

团队的 PagerDuty 价值是「让 incident 快速发现 + 快速解决」。前提是有 incident、需要快速发现、需要快速解决。solo engineer 没这个问题——我没 incident、commit log = 发现、commit = 解决。

一人工程的 PagerDuty = Vercel Edge Function + 我自己。不是 PagerDuty $41/user/月。
