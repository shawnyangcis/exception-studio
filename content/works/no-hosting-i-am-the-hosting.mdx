团队有 hosting。

Hosting：部署平台。Vercel：Next.js 部署。Netlify：static site + edge。Cloudflare Pages：Cloudflare CDN + edge。AWS Amplify：AWS deployment。Render：modern PaaS。Fly.io：edge PaaS。Heroku：classic PaaS。$20-$500 / 月 each.

每 startup 1 个 Vercel + 1 个 Netlify + 1 个 Cloudflare。$50-$500 / 月 in hosting。

solo engineer 没有 hosting。

我自己就是 hosting。

我想 deploy 就 deploy、想 host 就 host、想 scale 就 scale、想 serve 就 serve。我不需要 hosting、不需要 Vercel、不需要 Netlify、不需要 Cloudflare Pages、不需要 AWS Amplify、不需要 Render、不需要 Fly.io。

我没 hosting 的必要——Vercel 就是 hosting。我没 Vercel 的必要——Vercel 我已经在用。我没 Netlify 的必要——Vercel > Netlify。我没 Cloudflare Pages 的必要——Vercel + Cloudflare 是组合。我没 AWS Amplify 的必要——没 AWS。我没 Render 的必要——没 Render。我没 Fly.io 的必要——没 Fly。我没 Heroku 的必要——没 Heroku。我没 $20-$500 / 月 的必要——Vercel $20/月。我没 $50-$500 / 月 的必要——Vercel + 散文 = hosting。

团队的 hosting 价值是「让 web app 在 production 上跑 + auto-scale + 全球 CDN」。前提是有 web app、需要 production、需要全球 CDN。solo engineer 没这个问题——我的散文 = web app、Vercel auto-scale、Vercel CDN 是全球的。

一人工程的 hosting = Vercel $20/月 + Cloudflare 免费。不是 Netlify + AWS Amplify $500/月。
