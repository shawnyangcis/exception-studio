团队有 pair programming。

Pair programming：2 个人共用 1 台电脑。Driver：写代码。Navigator：review、思考下一步。每 30 分钟切换。Mob programming：3-6 个人一起写。Remote pair：2 个人通过 VS Code Live Share / Tuple / Zoom 协作。

每个 PR 都 pair = 1 个 senior + 1 个 junior，2 倍工时。

solo engineer 没有 pair programming。

我自己 pair。

我自己 driver + 自己 navigator：我写 30 分钟、看 5 分钟、再写 30 分钟。或者我写一个 function、站起来走一圈、回来看自己写的有没有问题。

我没 pair programming 的必要——我没 partner。我没 mob programming 的必要——没 mob。我没 remote pair 的必要——没人远程。我没 driver + navigator 切换的必要——我自己切换。

团队的 pair programming 价值是「知识共享 + 早期 catch bug + 教学」。前提是成员多、需要 spread knowledge、需要 on-the-job training。solo engineer 没这个问题——我知道我自己要做什么、bug 我自己 catch、教学我自己学。

一人工程的 pair = 我写半小时、看 5 分钟、再写半小时。不是 2 倍工时。
