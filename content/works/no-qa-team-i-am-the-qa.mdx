团队有 QA team。

QA team：质量保证 team。Quality assurance：质量保证。Test engineer：测试工程师。QA lead：QA lead。Test case：测试用例。Test plan：测试计划。Bug verification：bug 验证。Test automation：自动化测试。QA process：QA 流程。$80K-$150K / 年。

每个 startup 1 个 QA team + 1 个 QA lead + 1 个 test engineer。$200K-$400K / 年。

solo engineer 没有 QA team。

我自己就是 QA。

我想测就测、想写测试就写测试、想跑就跑、想 fix 就 fix。我不需要 QA team、不需要 QA lead、不需要 test engineer、不需要 test case、不需要 test plan。

我没 QA team 的必要——没 team 要 verify。我没 quality assurance 的必要——我 = quality。我没 test engineer 的必要——我 = tester。我没 QA lead 的必要——没 lead 要 align。我没 test case 的必要——commit = case。我没 test plan 的必要——commit log 是 plan。我没 bug verification 的必要——bug = commit revert。我没 test automation 的必要——commit hook = automation。我没 QA process 的必要——commit log 是 process。我没 $80K-$150K / 年 的必要——没 QA。

团队的 QA team 价值是「确保产品质量 + 找 bug + 验证 fix」。前提是有产品、有用户、需要 bug detection。solo engineer 没这个问题——我没产品、commit log = bug detection、我 = bug fixer。

一人工程的 QA = 我自己 + commit + test。不是 $200K QA team。
