debloat.dev。

一个域名。一份论坛。213 个项目。165 条帖子。5 万日活。

「replace the junk — open-source replacements for bloated vendor software」。

## 三个事实

### 1. 一人站 + 论坛形态

任何人可以发帖。无需账号。

GreenWithEnvy（NVIDIA 控制替代）+ Foqos + Liwan + Zen（Adblock）+ NewPipe（YouTube）+ ckb-next（Corsair iCUE）+ pymobiledevice3（iTunes）+ Syncthing（vendor cloud sync）+ Jellyfin（Plex）+ Home Assistant（Tuya）+ QMK（keyboard firmware）+ ESPHome（vendor cloud firmware）+ Immich（Google Photos）+ LocalSend（AirDrop）+ 200+ 其他项目。

每个项目是一行标题 + 替换对象 + license + 评论数 + 评分。

### 2. NO TRACKING NO COOKIES

页脚原文：

> NO TRACKING
> NO COOKIES*
> SSR
> *one cookie if you sign in

`llms.txt` 存在 — 给 LLM 读的 sitemap。

邮件联系方式：debloat@ryan.ceo。

一个人 + 论坛 + 反膨胀。

### 3. SSR + llms.txt + API + RSS + sitemap

技术栈：

- SSR (server-side render)
- 没有客户端 JavaScript 追踪
- `api` 端点
- `rss` 订阅
- `sitemap`
- `llms.txt`

一个人不需要 SaaS analytics。一个人不需要 Google Tag Manager。一个人不需要 HubSpot。

一个人 = 一份论坛 + 一份 RSS + 一份 sitemap + 一份 llms.txt。

## 三组对照

- NO TRACKING NO COOKIES

**表征不同。工具同根。**

debloat.dev = 论坛表征 = single page of 213 listings。
散文站 = 散文表征 = single page per MDX。

**solo engineer 选表征 = 工具涌现。**

### debloat.dev vs vendor forum

Reddit / Hacker News / Vercel Community：

- 大公司论坛 = SaaS + analytics + ad + tracking
- 用户行为被卖给广告商
- 帖子被降权 / 升权 / A/B 测试
- 算法决定你看什么

debloat.dev：

- 一个域名 + 一个论坛 = 没有算法
- 帖子按时间 / 评分排序 = 透明
- 任何人都能发帖 = 平等
- 一个人维护 = 没有利益冲突

**debloat.dev = 反 vendor 论坛的 solo engineer 版本。**
