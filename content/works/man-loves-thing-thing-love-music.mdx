plink / note / training / ship / realtime / pipeline / readme / evaluation 八层抽象之后，第九层是 love。

## love 是什么

love = solo engineer 做 AI 音乐的核心动机 = 不是钱 / 不是 reputation / 不是 market。

simedw 在 HN 帖写过：「我做这个项目是因为我想听 AI 帮我作曲。不是为了卖 App Store，是为了我自己想听。」

商业化是 App Store 上线后的副产物。love 是起因。

## love 是抽象层第九层

plink = 抽象层 1（领域）
note = 抽象层 2（表示）
training = 抽象层 3（方法）
ship = 抽象层 4（部署）
realtime = 抽象层 5（运行模式）
pipeline = 抽象层 6（流程）
readme = 抽象层 7（文档）
evaluation = 抽象层 8（评测）
love = 抽象层 9（动机）

love 跟其他八个不同：其他八个是工程 / 文档层，love 是动机层。

前八层回答「怎么造」，love 回答「为什么造」。

## love 是 solo engineer 的起点

大公司项目：起点是商业计划书（business plan）+ market research + revenue projection。

一人工程：起点是 simedw 自己想听 AI 帮他作曲。

商业计划书 vs 个人欲望。前者由团队执行，后者由 solo engineer 自己执行。

动机不同，路径不同，commit log 不同。

## love 跟 money 的对照

solo engineer 选 love 不选 money：

- love：solo engineer 自己享受过程 + 自己听自己做的 AI + 兴趣驱动
- money：用户付费 + App Store 月收入 + 用户增长 + 营销漏斗

simedw App Store 上线后有收入，但收入不是 simedw 写 MIDI transformer 的起点。

如果 simedw 起点是 money，他会选 high-frequency trading / 推荐系统 / 广告投放。这些 AI 应用商业化更直接。

simedw 选 MIDI transformer，因为 love。

## love 是一人工程的本质

love 是一人工程的本质。9 层抽象里，love 是最深的一层。

前 8 层是 solo engineer 能写在 README 里的。love 是 solo engineer 写在心里的。

8 层工程 + 1 层动机 = 一人工程全部。

## 洞穴人第九个代词

plink / note / training / ship / realtime / pipeline / readme / evaluation / love 九层抽象：

- plink = 领域

洞穴人九个词，描述 AI 音乐的九个抽象层。

simedw love 走完 motivation 全程。一人工程的动机在 1 个人 + 9 层抽象 + 1 个 love 里完成。
