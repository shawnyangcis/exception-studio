# GitHub README 第一版

> simedw 在 GitHub 上发布了 simedw/midi-autocomplete 项目。
> README 第一版是什么？

GitHub 项目结构：

- README.md
- LICENSE（MIT）
- src/
- scripts/
- requirements.txt
- configs/

README 第一版结构：

- 项目名
- 一句话描述
- 安装步骤
- 使用方法
- 训练步骤
- 评估步骤
- 部署步骤
- 采样切换
- 引用

一句话描述：

> 「A 125M transformer that autocompletes piano MIDI. Trained in PyTorch, deployed via Core ML to iOS.」

安装步骤：

- pip install -r requirements.txt
- python -m midi_autocomplete.generate --model path/to/64m.pt

训练步骤：

- python -m midi_autocomplete.train --config configs/64m.yaml

部署步骤：

- coremltools convert --model 64m.pt
- output.mlmodel → Xcode project

采样切换：

- top-k / top-p / min-p / XTC / top-h / Mirostat v2
- 在 iOS app 里切换

引用：

- LLaMA 架构
- DPO paper
- scheduled sampling paper
