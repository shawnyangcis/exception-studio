plink / note / training / ship / realtime / pipeline / readme / evaluation / love / privacy 十层抽象之后，第十一层是 future。

## future 是什么

future = solo engineer 项目的下一步 = simedw 14 个 commit 之后的 3 个 plan。

simedw 在 HN show 帖和 README 末尾提到下一步：

1. bar / measure token —— 给模型加小节标记，提升节奏感
2. longer-term planning —— 类似 CoT 的 planning step
3. parallel continuation picking —— 并行生成多个续写，挑最好的

3 个下一步对应未来层 3 个抽象。

## future 是抽象层第十一层

plink = 抽象层 1（领域）
note = 抽象层 2（表示）
training = 抽象层 3（方法）
ship = 抽象层 4（部署）
realtime = 抽象层 5（运行模式）
pipeline = 抽象层 6（流程）
readme = 抽象层 7（文档）
evaluation = 抽象层 8（评测）
love = 抽象层 9（动机）
privacy = 抽象层 10（隐私）
future = 抽象层 11（未来）

future 跟其他十个不同：其他十个是当前层，future 是 next-step 层。

前十层回答「现在是什么」，future 回答「下一步是什么」。

## future 是 solo engineer 的视野

大公司项目：future = 产品路线图（product roadmap）+ 季度规划 + 年度规划 + 3 年战略。

一人工程：future = simedw README 末尾的 3 个 bullet。

产品路线图 vs 3 个 bullet。前者由 10+ 人执行，后者由 1 个人执行。

3 个 bullet 是 solo engineer 视野的真实边界——能想多远，想多准，做多少，都受限于同一个人。

## future 跟 plan 的对照

solo engineer 选 bullet 不选 plan：

- bullet：simedw 自己在 README 写的 3 步
- plan：产品团队（5+ 人）写的季度 OKR + KR + 任务依赖图

simedw bullet 比大公司 plan 更模糊，但更灵活。

bullet 模糊 = 可以随时改（改 bullet 不需要会议）。
plan 详细 = 不能随便改（改 plan 需要评审）。

solo engineer 选 bullet，因为灵活 > 详细。

## future 是一人工程的扩张

simedw 未来 3 步走完，一人工程扩张到下一个项目：

- 项目 1：MIDI transformer for piano（已上线）
- 项目 2：?（simedw bullet 之后做什么？）
- 项目 3：?（更大的图）

simedw bullet 是项目 1 的扩张。下一个项目是 simedw 自己的选择。

solo engineer 选下一个项目的方式 = bullet 改写 + commit log 重启。

Continuator Pachet 2003 → simedw 2026 是 23 年的同一条线。23 年后下一个 solo engineer 会做下一个 23 年的项目。
