## 洞穴人格式是什么

- man：原始人（man）
- hits：原始动作（hits）

## plink vs note 的对照

plink：

- 通用 AI 音乐代名词
- 不知道是什么音（plink 是什么都行）
- 抽象层：最高（任何音都是 plink）
- 适合：哲学讨论 + 简化叙事

note：

- 具体 AI 音乐代名词
- 知道是什么音（C / D / E / F / G / A / B）
- 抽象层：具体（note = C / D / E / F / G / A / B）
- 适合：技术讨论 + 具体生成

2 个对照。

## 洞穴人格式的哲学

洞穴人格式哲学：

- 简化 > 复杂（man hits thing go plink 描述任何 AI 音乐）
