团队有 Slack。

Slack：团队聊天。Discord：社区聊天。Microsoft Teams：enterprise 聊天。Mattermost：open source Slack。Rocket.Chat：open source chat。$6-$15 / user / 月.

每 startup 1 个 Slack + 1 个 IT admin + 1 个 communication policy。$100K-$300K / 年。

solo engineer 没有 Slack。

我自己就是 Slack。

我想 chat 就 chat、想 message 就 message、想 DM 就 DM、想 channel 就 channel。我不需要 Slack、不需要 Discord、不需要 Teams、不需要 Mattermost。

我没 Slack 的必要——访问量 1000 不需要 chat。我没 Discord 的必要——没 Discord。我没 Microsoft Teams 的必要——没 enterprise chat。我没 Mattermost 的必要——没 Mattermost。我没 Rocket.Chat 的必要——没 Rocket.Chat。我没 $6-$15 / user / 月 的必要——Vercel free。我没 IT admin 的必要——没 IT admin。我没 communication policy 的必要——没 policy。我没 $100K-$300K / 年 的必要——没 chat subscription。

团队的 Slack 价值是「让 team 实时沟通 + 信息透明」。前提是有 team、需要 async、需要 visibility。solo engineer 没这个问题——我没 team、不需要 async、commit log = visibility。

一人工程的 Slack = 我自己 + 散文。不是 Slack $12/user/月。
