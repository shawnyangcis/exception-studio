## bullet 1：bar/measure token（表征层）

bar/measure token：

- 一个 bar（小节）一个 token
- 多个 note 合成一个 bar
- 上下文信息量更大

3 个 bar/measure token 特点。

bar/measure token 的优势：

- 表征层 = 5× speedup（compound note events 类似哲学）
- 长上下文信息量更大
- 模型推理更稳定

3 个 bar/measure token 优势。

跟 NOTE 单 token 的对照：

- NOTE 单 token = 1 音 = 1 token
- bar/measure token = 1 小节 = 1 token
- bar/measure > NOTE 单 token（信息密度更大）
- simedw 想升级 NOTE 单 token 到 bar/measure

4 个对照。

## bullet 2：longer-term planning（推理层）

longer-term planning：

- 模型预测更长上下文
- 不只预测下一个音，预测下一段音乐
- 类似 chain-of-thought 但用于音乐

3 个 longer-term planning 特点。

longer-term planning 的优势：

- 推理层 > 暴力层（不要暴力 sampling）
- 长上下文一致性
- 风格连贯

3 个 longer-term planning 优势。

## bullet 3：parallel continuation picking（选择层）

parallel continuation picking：

- 并行生成多个续写
- 选最好的一个（评测选）
- 不只单次生成

3 个 parallel continuation picking 特点。

parallel continuation picking 的优势：

- 选择层 > 单次层（不只生成一个）
- 多选择 = 评测驱动
- 质量提升

3 个 parallel continuation picking 优势。
