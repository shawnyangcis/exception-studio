团队有 spike。

Time-boxed investigation：2 天时间调研一个技术问题。PoC（Proof of Concept）：快速验证可行性。Prototype：做出可点击的 demo。技术调研：开会、读论文、benchmark、汇总。输出：deck + 推荐方案 + 时间表。

调研完写一份 30 页调研报告 + 50 张 benchmark 图 + 4 个 stack overflow 答案。3 周。

solo engineer 没有 spike。

我自己 try。

我想 try 一个库就 `npm install`、我想 try 一个 API 就 `curl`、我想 try 一个 idea 就写 50 行 throw-away code。throw-away code 也是进度——我知道这个 idea 不 work 了，我不必再花时间。

我没 time-boxed investigation 的必要——我没 deadline、没人等结果。我没 PoC 的必要——我不需要说服别人可行性。我没 prototype 的必要——demo 不需要、可工作的散文就是 demo。我没 30 页调研报告 的必要——commit message 描述清楚就行。

团队的 spike 价值是「多人公司需要调研共识」。前提是改动大、需要 buy-in、需要 stakeholder 同意。solo engineer 没这个问题——我 try 完知道行不行，commit 或 revert。

一人工程的 spike = `throw-away code`。不是 30 页 deck。
