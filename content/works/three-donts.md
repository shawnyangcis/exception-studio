# 三个不做

2026 年，有一个终端助手说自己不用 LLM。

TERMy — A fast terminal assistant that does not use LLMs。HN 上 117 分，31 条评论。大部分人第一反应是：你疯了吗？

## 一、不做 AI

2026 年做软件，默认就是加 LLM。写代码用 Copilot，写文案用 ChatGPT，做助手用 Claude。不加 AI 的产品，就像不加糖的咖啡 — 不是不行，是没人理解为什么要这样。

但 TERMy 的作者 gioscarab 偏偏选择了不加。

理由很简单：终端助手需要的是快、准、安静。LLM 太慢了，太吵了，太喜欢「解释」了。一个帮你查文件、跑命令、切换目录的工具，为什么要先跟你聊两句？

这不是反 AI，是知道什么时候不做。

## 二、不做多余

TERMy 的 GitHub 主页写着：NPC-Forge，111 stars，131 commits，1000 行代码。

1000 行。不是 10 万行，不是微服务架构，不是「平台」。就是 1000 行代码，做一件事，做好。

tw93 说过「不做什么远比做什么重要」。放到 TERMy 上，这句话变成了「不做什么远比加什么重要」。不加 LLM 是第一次「不做」，不加功能是第二次「不做」，不加依赖是第三次「不做」。

三个不做之后，剩下的东西就特别干净。

## 三、不做声

TERMy 没有博客，没有 Twitter 营销，没有「为什么我不用 LLM」的宣言。它就是出现在 HN 上，117 分，31 条评论，然后安静地待在 GitHub 里。

你想用就用，不用就不用。它不会追着你问「为什么不给个 star」。

这才是安静守护者哲学的真正体现：不是做了什么让你看见，是没做什么让你感觉不到它的存在。

## 四、不做的代价

当然，三个不做有代价。

117 分在 HN 上不算高。1000 行代码在 GitHub 上不算多。没有 LLM 在 2026 年不算「创新」。

但 gioscarab 似乎不在乎。他在 HN 评论区说了一句话：「I just wanted a fast terminal assistant. I didn't want a chatbot.」

一个快的终端助手。不是一个聊天机器人。

这句话的潜台词是：我知道外面有什么，我选择不要。

## 五、散文站的三个不做

写散文站我也给自己定了三个不做：

**不追热点**。HN 上什么火就写什么，那是 newsletter，不是散文。

**不批量产出**。一天写十篇，那是内容农场，不是写作。

**不刷存在感**。每天发「在吗」「更新一下」，那是营销，不是品牌建设。

三个不做之后，剩下的东西就特别安静。

安静不是没有，是知道什么时候不做。
